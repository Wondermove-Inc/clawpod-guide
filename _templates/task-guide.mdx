# 작업 제목

이 가이드를 마치면 무엇을 완료할 수 있는지 한 문장으로 설명합니다.

## 시작하기 전에

- 필요한 역할 또는 권한
- 필요한 요금제 또는 사전 설정
- 이 작업을 하면 안 되는 경우

## 실행 방법

1. Portal에서 실제 메뉴 이름을 사용해 첫 단계를 설명합니다.
2. 한 단계에 하나의 행동만 씁니다.
3. 입력 예시는 Secret이나 실제 고객 데이터를 포함하지 않습니다.

## 정상적으로 완료되면

사용자가 확인할 수 있는 결과를 씁니다.
