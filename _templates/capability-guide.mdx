# Capability 이름

## 할 수 있는 일

이 capability로 Agent가 수행할 수 있는 사용자 가치와 한계를 설명합니다.

## 지원 상태

| 항목 | 값 |
| --- | --- |
| 상태 | 기본 제공 / 설정 필요 / 권한 필요 / Preview |
| 필요한 Agent release | 확인된 최소 release |
| 필요한 역할 | 실제 역할 또는 권한 |
| 설치 또는 연결 | Skill, provider, channel, device 등 |
| 데이터 접근 | 읽기, 쓰기, 외부 전송 여부 |

## 활성화 방법

1. 지원 여부를 확인합니다.
2. 필요한 설치 또는 연결을 완료합니다.
3. 최소 권한을 부여합니다.
4. 테스트 입력으로 정상 동작을 확인합니다.

## Agent 사용 방법

사용자가 Agent에게 요청할 수 있는 예시와, Agent가 실행 전 확인해야 하는 조건을 씁니다.

## 중지·제거

연결 해제, credential binding 해제, 권한 회수, 남은 데이터 또는 결과물 영향을 순서대로 설명합니다.

## 문제 해결

| 상황 | 원인 | 해결 방법 |
| --- | --- | --- |
| 기능이 보이지 않음 | 권한, 설치 또는 지원 상태 | 각 조건을 확인합니다. |
