# 도움말

문제가 생기면 먼저 아래를 확인하세요.

1. 현재 조직과 계정이 맞는지 확인합니다.
2. 필요한 메뉴나 버튼이 보이지 않으면 역할과 권한을 확인합니다.
3. Agent가 사용할 model과 credential이 조직에 연결되어 있는지 확인합니다.
4. 문제가 계속되면 오류 화면의 시간, 수행한 작업, Agent 이름을 정리해 조직 관리자 또는 지원팀에 전달합니다.

Secret, access token, API key, 고객 대화 전문은 지원 요청에 포함하지 마세요.
