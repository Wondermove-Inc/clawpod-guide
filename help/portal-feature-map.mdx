# Portal 메뉴와 가이드 찾기

화면 상단의 **채팅 / 관리자** 전환에 따라 왼쪽 메뉴가 바뀝니다. 먼저 계정 메뉴에 표시된 역할을 확인하세요. 아래 관리 메뉴는 테넌트 관리자 화면을 기준으로 정리했으며, 일반 사용자의 메뉴는 부여된 권한과 조직 설정에 따라 더 적을 수 있습니다.

## 채팅과 개인 설정

| 위치 | 할 수 있는 일 | 가이드 |
| --- | --- | --- |
| 상단 채팅 → 새 채팅·채팅방 검색 | Agent와 대화하고 방 찾기 | [Chat Room](../guides/use-chat-room.mdx), [이전 대화](../guides/use-chat-archive.mdx) |
| 채팅방 → 메시지 검색 | 불러온 메시지에서 검색 | [메시지 찾기](../guides/use-chat-room.mdx) |
| 채팅방 → 워크스페이스 열기 | 현재 방의 PC·ClawPod 컨트롤, 워크보드, Artifacts, 회의록 도구 확인 | [Desktop](../guides/use-agent-desktop.mdx), [결과물](../guides/file-formats-and-artifacts.mdx), [회의록](../guides/use-meeting-minutes.mdx) |
| 왼쪽 아래 계정 → 설정 | 프로필·비밀번호·MFA, 외관, 알림 | [계정 설정](../guides/manage-account-and-organization.mdx), [보안](../guides/secure-your-account.mdx) |
| 왼쪽 아래 계정 → 언어 | Portal 표시 언어 선택 | [언어 설정](../guides/manage-account-and-organization.mdx) |
| 상단 알림 → 모든 알림 보기 | 알림 목록과 전달 설정 확인 | [알림](../guides/manage-notifications.mdx) |

채팅 워크스페이스의 워크보드와 관리자 메뉴의 조직별 태스크는 서로 다른 화면입니다. 도구 수와 사용 가능 여부는 선택한 Room과 Agent 상태에 따라 달라집니다.

## 테넌트 관리자 메뉴

상단 **관리자**를 선택한 뒤 다음 메뉴를 사용합니다. 아래 표는 모든 일반 사용자에게 같은 메뉴가 보인다는 의미가 아닙니다.

| 메뉴 구역 | 표시되는 메뉴 | 가이드 |
| --- | --- | --- |
| 시작 | 온보딩 | [새 workspace 준비](../guides/complete-onboarding.mdx) |
| 시작 | 대시보드 | [대시보드](../guides/use-dashboard-and-costs.mdx), [사용량 확인](../guides/check-workspace-and-system.mdx) |
| 관리 | 에이전트 | [생성](../guides/create-agent.mdx), [상태·설정](../guides/manage-agent.mdx) |
| 관리 | 조직 | [조직·멤버 관리](../guides/manage-organization.mdx) |
| 관리 | 태스크 | [Tasks와 Milestone](../guides/use-tasks-and-milestones.mdx) |
| 분석 | 분석 요약, LLM 사용 비용 | [분석과 비용](../guides/use-analytics.mdx) |
| 연동 | 웹훅 | [Webhook](../guides/send-webhook-to-agent.mdx) |
| 연동 | AI 키 관리 | [AI 연결](../guides/manage-credentials.mdx) |
| 플랫폼 | 공지 관리 | [테넌트 공지](../guides/manage-announcements.mdx) |
| 플랫폼 | 요금제 관리 | [구독과 결제 내역](../guides/manage-billing.mdx) |
| 보안 | 사용자 관리 | [IAM 사용자·정책](../guides/manage-iam.mdx) |
| 보안 | 감사 로그 | [감사 기록](../guides/use-audit-log.mdx) |

테넌트 관리자가 **요금제 관리**를 누르면 결제 관리 화면으로 연결됩니다. 플랜 목록·가격을 편집하는 플랫폼 최고 관리자 화면과 구분하세요.

## 메뉴가 보이지 않을 때

역할, 현재 조직, 상단 모드와 허용된 메뉴를 확인하세요. 그래도 필요한 메뉴가 없으면 테넌트 관리자에게 문의합니다. **Documents, 별도 AI Chat·Chat Archive, 설정의 Workspace·System, Monitoring**을 고객의 기본 진입 경로로 안내하지 않습니다. 메뉴가 없다는 이유만으로 URL을 추측하거나 권한을 확대하지 마세요.
