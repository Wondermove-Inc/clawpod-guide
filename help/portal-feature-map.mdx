## 별도 확인이 필요한 항목

- **API Keys settings**는 현재 소비자용 API key 발급 화면이 아닙니다. [catalog의 retired 항목](/capabilities/catalog)을 참고하세요.
- tenant, global language, menu visibility, model pricing, Agent preset 같은 항목은 일반 조직 운영 기능이 아니라 Platform 관리자 경계입니다. **Legacy Workflow route**는 권한·tenant 경계가 소비자 기능으로 확인되지 않아 사용 경로로 안내하지 않습니다.
- runtime source에만 있는 channel, device, voice, plugin 기능은 현재 Cloud 소비자 기능이 아닙니다. Portal 연결·회수 경로가 없으므로 설정을 시도하지 말고 [숨겨진 Agent 기능의 소비자 제공 상태](/capabilities/consumer-availability)를 따르세요.
- Agent의 browser control·CLI 작업은 [Browser와 CLI 작업 요청](/guides/use-browser-and-cli)에서 실행 조건과 승인 범위를 확인하세요.
