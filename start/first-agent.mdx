# 첫 Agent 만들기

이 가이드를 마치면 팀의 목적에 맞는 첫 AI Agent를 만들고 대화를 시작할 수 있습니다.

## 시작하기 전에

- Agent 생성 권한이 필요합니다. 메뉴가 보이지 않으면 조직 관리자에게 권한을 요청하세요.
- 사용할 AI credential이 필요합니다. 조직 정책에 따라 저장된 credential을 선택하거나 생성 과정에서 제공할 수 있습니다.
- Agent가 맡을 업무를 한 문장으로 정해 두면 설정이 쉬워집니다. 예: “고객 문의 초안을 작성하는 지원 Agent”.

## Agent 만들기

1. Portal의 **<!-- ui-label: nav.agents -->에이전트<!-- /ui-label -->**로 이동한 뒤 **<!-- ui-label: pages.agents.createAgent -->새 팀원 추가<!-- /ui-label -->**를 선택합니다.
2. Agent의 이름과 역할을 정합니다. 제공되는 역할 프리셋을 선택하거나 직접 구성할 수 있습니다.
3. Agent가 사용할 model과 credential을 선택합니다. 선택 가능한 항목은 조직의 설정과 권한에 따라 달라집니다.
4. Agent가 해야 할 일, 말투, 피해야 할 일을 설명하는 기본 지침을 검토하고 필요한 부분을 수정합니다.
5. 설정을 확인한 뒤 **<!-- ui-label: agentCreateV2.hireExpert -->이 전문가 채용<!-- /ui-label -->**을 선택하고, Review 대화상자에서 **<!-- ui-label: reviewDialog.confirmCreate -->확인 및 생성<!-- /ui-label -->**을 선택합니다.

## 정상적으로 완료되면

새 Agent가 Agents 목록에 표시됩니다. Agent를 열어 상태와 기본 설정을 확인한 후, Chat에서 첫 메시지를 보내 보세요.

## 문제가 생기면

| 상황 | 먼저 확인할 사항 |
| --- | --- |
| Create Agent가 보이지 않음 | Agent 생성 권한이 있는지 확인합니다. |
| model 또는 credential을 선택할 수 없음 | 조직에 사용 가능한 credential이 있는지, 해당 credential 사용 권한이 있는지 확인합니다. |
| 생성 후 대화할 수 없음 | Agent 상태를 확인하고, 조직 관리자에게 연결 설정 확인을 요청합니다. |

Credential 값이나 access token은 채팅, 문서, 지원 요청에 공유하지 마세요.
