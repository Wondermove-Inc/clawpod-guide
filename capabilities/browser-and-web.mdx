# Browser와 웹 작업

브라우저를 사용할 수 있는 Agent에게 웹 페이지 읽기, 탐색, 입력과 화면 확인을 요청할 수 있습니다. 데스크톱이 없는 경량 Agent는 GUI 브라우저 작업을 지원하지 않으므로 대상 Agent의 준비 상태를 먼저 확인하세요.

## 시작하기 전에

- 대상 사이트와 사용할 계정에 대한 접근 권한이 필요합니다.
- Agent가 브라우저를 실행하고 대상 URL에 접근할 수 있어야 합니다.
- 로그인 정보, 쿠키와 다운로드 파일은 민감한 정보로 다룹니다.

일반 사용자가 모든 Agent 실행 환경을 직접 선택하는 것은 아닙니다. 브라우저 작업이 필요한데 준비되지 않았다면 관리자에게 필요한 작업과 대상 Agent를 알려 주세요.

## 요청하고 확인하기

1. 대상 URL과 원하는 결과를 적습니다.
2. 읽기, 입력, 제출, 다운로드와 외부 전송 중 허용한 범위를 명시합니다.
3. 작은 읽기 요청으로 접근 가능 여부를 확인합니다.
4. 결과의 출처 URL, 실제 변경, 실패한 단계를 확인합니다.

구체적인 요청 예시와 파일 작업 방법은 [Browser와 CLI 작업 요청](../guides/use-browser-and-cli.mdx)을 참고하세요. 사람 확인이나 추가 로그인이 필요하면 Agent가 멈추고 필요한 조치를 알리도록 합니다.

## AI Chat 검색과 구분하기

[AI Chat의 웹 검색](../guides/use-ai-chat.mdx)은 Portal의 별도 기능입니다. AI Chat에서 검색된다는 이유로 모든 Agent에 같은 검색 도구가 연결됐다고 보지 마세요. Agent의 도구가 확인되지 않으면 대상 URL을 지정한 브라우저 작업부터 가능한지 확인합니다.

작업 범위를 지침으로 적는 것과 제품이 해당 제한을 자동으로 강제하는 것은 다릅니다. 조직의 접근·외부 전송 정책을 함께 따라야 합니다.
