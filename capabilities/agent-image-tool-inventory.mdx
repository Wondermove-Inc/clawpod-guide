# Agent image 도구 목록

이 페이지는 현재 ClawPod Agent image 정의에 **포함된 도구**를 설명합니다. 포함은 Agent가 해당 도구를 무제한으로 실행하거나 외부 서비스에 로그인할 수 있다는 뜻이 아닙니다. 작업 범위는 Agent 정책, credential, 네트워크, workspace 권한을 따릅니다.

## 두 이미지에 공통으로 포함되는 도구

| 범주 | 포함 항목 | 사용하는 경우 |
| --- | --- | --- |
| Agent runtime | OpenClaw, MCP client `mcporter`, A2A MCP, Skill Store MCP, ClawPod Guide MCP | Agent 실행, 다른 Agent와 Room 기반 협업, Marketplace Skill 사용, 공개 제품 문서 원격 검색·읽기 |
| 개발·명령줄 | Node.js 22, npm, yarn, pnpm, TypeScript, `tsx`, `ts-node` | JavaScript·TypeScript 작업과 package 실행 |
| 기본 명령줄 | Git, GitHub CLI `gh`, curl, wget, HTTPie, jq, ripgrep, tmux, SSH client, rsync | 코드·HTTP·Git·로그·원격 작업 |
| Python | Python 3, pip, `requests`, `httpx`, YAML·TOML 도구 | 스크립트와 API 작업 |
| 기본 Skill | `cli-anything` | 지원되는 application 또는 source repository용 CLI harness 작업 |

이미지는 Claude Code와 Codex CLI 설치를 시도하지만 image build 시 package를 받을 수 없으면 해당 CLI를 건너뜁니다. 따라서 이 둘을 작업에 반드시 써야 한다면 Agent에게 먼저 사용 가능한 명령을 읽기 전용으로 확인하도록 요청하세요.

## full image에만 포함되는 도구

`clawpod/agent` full image는 경량 image에 더해 다음을 포함합니다.

| 범주 | 포함 항목 | 사용하는 경우 |
| --- | --- | --- |
| Desktop | XFCE, Xvfb, x11vnc, noVNC, xdotool, AT-SPI | [Agent Desktop](/guides/use-agent-desktop)과 GUI 자동화 |
| Browser | Chromium, Playwright MCP | 페이지 탐색, snapshot, screenshot, 입력·클릭 |
| 문서·media | LibreOffice, GIMP, ffmpeg, PulseAudio | Office 문서, 이미지, 음성·영상 파일 처리 |
| 개발 환경 | Go, Rust, C/C++ build tools, CMake, Python venv·개발 도구 | build·compile·test 작업 |
| Python 분석 | pandas, openpyxl, `black`, `ruff`, `mypy`, `pytest` | CSV·XLSX 분석과 Python 품질 검사 |
| 기본 Skill | `desktop`, `tasks`, `cli-anything` | GUI 제어, Task 작업, CLI harness |

Browser·Desktop·LibreOffice·media 작업이 필요하면 플랫폼 최고 관리자가 Agent 생성 시 full image를 선택합니다. 일반 사용자는 image를 직접 선택하지 못하며, 생성 화면은 사용 가능한 full image를 우선 선택합니다.

## 경량 image에서 제외되는 항목

`clawpod/agent-lite`는 GUI 없이 명령줄 중심으로 동작합니다. 다음은 포함하지 않습니다.

- Chromium, XFCE/Xvfb, VNC/noVNC, desktop Skill
- LibreOffice, GIMP, ffmpeg, PulseAudio
- Go·Rust와 full image의 data-science Python 도구
- SMB/CIFS와 GUI용 font·audio 구성

따라서 경량 image에서 GUI browser, 원격 Desktop, Office 화면 조작, 영상 변환을 요청하지 마세요. CLI·파일·Git·HTTP·기본 Python 작업은 경량 image에서도 수행할 수 있습니다.

## image 밖의 기능

Channel adapter, device pairing, voice call, 외부 plugin, 임의 provider는 Agent source에 있을 수 있어도 image에 있다는 사실만으로 Cloud 사용 기능이 되지 않습니다. Portal 설정·credential·tenant lifecycle이 없는 항목은 [실행 capability matrix](/capabilities/agent-execution-matrix)의 source-only 경계를 따릅니다.
