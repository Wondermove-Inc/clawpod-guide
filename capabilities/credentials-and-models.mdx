# Credential과 model

Credential은 Agent가 model provider 또는 연동 서비스에 접근하기 위해 사용하는 tenant 단위 연결 정보입니다. 권한 있는 사용자가 같은 tenant의 Agent에 연결합니다. 값 자체는 문서, Chat, screenshot, 지원 요청에 공유하지 마세요.

## 할 수 있는 일

권한이 있는 사용자는 저장된 credential을 확인하고, 새 credential을 만들거나 값을 교체하며, local LLM 연결을 시험할 수 있습니다. Credential을 Agent에 연결하는 작업은 별도 사용·binding 권한을 요구할 수 있습니다.

## 연결 전 확인

1. **AI 키 관리**에서 Anthropic, OpenAI, OpenAI Codex `auth.json`, Google Gemini, OpenRouter, Ollama 또는 OpenAI-compatible local LLM 중 하나를 선택합니다.
2. credential의 소유 tenant와 대상 Agent가 일치하는지 확인합니다.
3. Agent에 필요한 최소 권한만 연결합니다.
4. local LLM은 연결 test 뒤 비민감 test Room 요청까지 실행합니다.
5. 교체·회수·삭제 시 연결된 Agent에 어떤 영향이 있는지 확인합니다.

## 교체와 회수

Credential 값 교체는 기존 연결을 사용하는 Agent에 영향을 줄 수 있습니다. 문제가 발생하면 원인을 확인하기 전까지 raw value를 다시 입력하거나 공유하지 말고, 연결 상태·권한·provider 응답을 확인하세요.

## Runtime provider capability

Portal에서 소비자가 연결하는 provider는 위 목록입니다. Agent runtime에 있는 임의 provider adapter, OAuth flow, plugin provider는 현재 Portal credential lifecycle이 없으므로 사용법을 제공하지 않습니다. model 역할(main·sub·fallback·heartbeat)의 선택·적용은 [Provider와 model 선택](/guides/select-models)을 따릅니다.
