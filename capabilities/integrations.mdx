# 연동 기능

ClawPod에서 AI 연결을 준비하고 외부 이벤트를 Webhook으로 전달할 수 있습니다. Resend와 Google Workspace는 Agent에게 능력 레지스트리의 스킬 설치와 계정 연결을 요청해 시작합니다.

| 필요한 연결 | 설정 가이드 | 정상 결과 확인 |
| --- | --- | --- |
| Agent가 사용할 AI 서비스 또는 Local LLM | [AI 키 관리](../guides/manage-credentials.mdx), [모델 선택](../guides/select-models.mdx) | 대상 Agent에서 작은 요청이 응답하는지 확인 |
| 외부 이벤트 전달 | [Webhook](../guides/send-webhook-to-agent.mdx) | Event 기록과 대상 Agent 또는 Room 확인 |
| 이미지 생성·음성 전사 | [이미지와 음성 작업](./channels-and-media.mdx) | AI 연결과 도구 준비 상태, 실제 결과물 확인 |
| Resend 이메일 발송 | [Resend 연결](../guides/use-resend-email.mdx) | 키·발신 도메인 검증과 테스트 메일 접수 확인 |
| Google 메일·일정·파일·문서 작업 | [Google Workspace 연결](../guides/use-google-workspace.mdx) | 계정 인증, 부여된 권한과 서비스 접근 확인 |
| Slack 채널에서 Agent와 대화 | [Slack 연결](../guides/use-slack.mdx) | 채널 시험 메시지와 사용자 멘션에 대한 응답 확인 |
| 웹사이트 방문자와 Agent 대화 | [웹챗 위젯 설치](../guides/use-webchat.mdx) | 설치한 사이트에서 방문자 메시지와 Agent 응답 확인 |

## 연결 전에 확인하기

연결할 조직과 Agent, 필요한 권한, 외부로 보낼 데이터 범위를 정하세요. 인증 정보는 각 서비스 가이드의 연결 절차로 관리하세요. Agent 업무용 API 키의 등록·사용은 [시크릿 다루기](../guides/handle-secrets.mdx)를 따르고, 일반 문서·공유 대화·Skill 패키지에는 값을 복사하지 않습니다.

## 연결 후 관리하기

설정 저장이나 요청 접수와 실제 사용 가능 상태는 다릅니다. 각 가이드의 정상 결과를 확인하고 비민감 데이터로 시험하세요. 실패하면 연결 상태와 오류를 확인한 뒤 다시 시도합니다.

더 이상 필요하지 않으면 해당 가이드에 따라 AI 연결을 해제하거나 Webhook Rule을 중지합니다. ClawPod에서 연결을 삭제해도 외부 서비스의 API key 자체가 폐기되는 것은 아닙니다.
