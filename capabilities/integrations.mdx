# 연동 기능

ClawPod에서 AI 연결을 준비하고 외부 이벤트를 Webhook으로 전달할 수 있습니다.

| 필요한 연결 | 설정 가이드 | 정상 결과 확인 |
| --- | --- | --- |
| Agent가 사용할 AI 서비스 또는 Local LLM | [AI 키 관리](../guides/manage-credentials.mdx), [모델 선택](../guides/select-models.mdx) | 대상 Agent에서 작은 요청이 응답하는지 확인 |
| 외부 이벤트 전달 | [Webhook](../guides/send-webhook-to-agent.mdx) | Event 기록과 대상 Agent 또는 Room 확인 |
| 이미지 생성·음성 전사 | [이미지와 음성 작업](./channels-and-media.mdx) | AI 연결과 도구 준비 상태, 실제 결과물 확인 |

## 연결 전에 확인하기

연결할 조직과 Agent, 필요한 권한, 외부로 보낼 데이터 범위를 정하세요. API key와 비밀값은 해당 설정 화면에 입력하고 대화·문서·Skill 패키지에 넣지 않습니다.

## 연결 후 관리하기

설정 저장이나 요청 접수와 실제 사용 가능 상태는 다릅니다. 각 가이드의 정상 결과를 확인하고 비민감 데이터로 시험하세요. 실패하면 연결 상태와 오류를 확인한 뒤 다시 시도합니다.

더 이상 필요하지 않으면 해당 가이드에 따라 AI 연결을 해제하거나 Webhook Rule을 중지합니다. ClawPod에서 연결을 삭제해도 외부 서비스의 API key 자체가 폐기되는 것은 아닙니다.
