# 이미지와 음성 작업

이미지 생성이나 음성 전사는 필요한 AI 연결과 도구가 준비된 Agent에게 요청할 수 있습니다. Portal의 채팅 음성 입력과 회의록은 별도 사용 흐름입니다.

## Agent에게 요청하기

1. [AI 키 관리](../guides/manage-credentials.mdx)에서 대상 Agent에 OpenAI Credential을 연결합니다.
2. Agent에게 요청한 작업에 필요한 도구가 사용 가능한지 확인하게 합니다. 연결만으로 모든 작업이 준비됐다고 가정하지 않습니다.
3. 사용할 입력, 원하는 이미지 또는 전사 결과, 비용 범위와 결과물 보존 범위를 지정합니다.
4. 작은 요청으로 결과를 확인하고 원하는 형식으로 받습니다.

비밀값은 대화에 붙여 넣지 마세요. 입력에 다른 사람의 음성이나 자료가 포함되면 사용 권한과 조직 정책을 먼저 확인합니다. 결과가 자동으로 Task에 등록된다고 가정하지 말고 [파일 형식과 결과물](../guides/file-formats-and-artifacts.mdx)에서 확인·다운로드 방법을 참고하세요.

## Portal에서 음성 사용하기

- 채팅에서 말로 입력하기: [Chat Room 음성 입력](../guides/use-chat-room.mdx)
- 회의를 전사하고 요약하기: [회의록 만들기](../guides/use-meeting-minutes.mdx)

## 실패하거나 중지할 때

AI 연결 상태, Agent의 도구 준비 상태, 입력 형식과 비용 한도를 확인합니다. 반복 요청 전에는 이전 요청이 이미 처리됐는지 확인하세요. 더 이상 쓰지 않는 연결은 [AI 키 관리](../guides/manage-credentials.mdx)의 해제 절차를 따르고 입력·결과물은 보존 정책에 맞게 정리합니다.
