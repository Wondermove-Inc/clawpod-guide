# 자동화와 Webhook

**자동화**에서 외부 이벤트, 정해진 일정, 채팅 메시지를 계기로 Agent가 할 일을 설정합니다. 필요한 권한과 대상 Agent·채팅방에 따라 만들거나 수정할 수 있는 항목이 달라집니다.

## 자동화 종류

| 종류 | 시작 조건 | 설정할 내용 |
| --- | --- | --- |
| 웹훅 | 외부 서비스에서 이벤트 수신 | 연결, 이벤트 조건, 받는 대상, 플레이북 |
| 일정 | 지정한 시각이나 반복 일정 | 매일·매주·매시간 또는 직접 입력한 cron 식, 표시된 시간대, Agent, 결과 받을 방, 할 일 |
| 메시지 | 지켜볼 방에 조건에 맞는 메시지 도착 | 지켜볼 방, 문구의 포함·같음·시작 조건, Agent, 결과 받을 방, 할 일 |

## Agent에게 만들기 요청하기

Agent와의 대화에서 원하는 시작 조건과 작업, 보고받을 위치를 알려주세요. **자동화 → 자동화 만들기 → 에이전트와 만들기**에서도 요청할 대화방을 선택할 수 있습니다.

> 매주 월요일 오전 9시에 이번 주 할 일을 정리해서 이 방에 알려줘. 사용할 시간대를 확인하고 필요한 정보가 있으면 물어봐.

> 이 방에 ‘배포 실패’가 들어간 메시지가 오면 관련 상황을 확인하고 결과를 알려주는 자동화를 만들어줘.

Agent가 필요한 정보를 확인하고 현재 제공되는 도구와 권한에 따라 설정하거나 제안합니다. 웹훅 제안의 검토·승인과 외부 서비스 등록은 [Webhook 연결 안내](../guides/send-webhook-to-agent.mdx)를 따르세요. 요청한 것만으로 활성화됐다고 판단하지 말고 실제 상태와 남은 설정을 확인하세요.

## 직접 만들기

1. **자동화 → 자동화 만들기 → 직접 만들기**를 엽니다.
2. **웹훅·일정·메시지** 중 종류를 선택합니다. 권한상 사용할 수 없는 종류는 선택할 수 없습니다.
3. 이름과 시작 조건을 입력합니다. 일정은 화면에 표시된 시간대를 확인하고, 메시지는 지켜볼 방과 문구 조건을 지정합니다.
4. 할 일과 담당 Agent, 결과 받을 방 또는 웹훅의 받는 대상을 설정합니다. 선택 가능한 Agent·방 목록을 기준으로 정하세요.
5. 생성 후 목록에서 활성 상태를 확인합니다. 설정이 남았거나 Agent의 확인 응답을 받지 못하면 만들어졌더라도 꺼진 상태일 수 있습니다. 안내된 설정 확인을 이어서 진행하세요.

웹훅은 보내는 서비스에 수신 URL과 필요한 시크릿을 등록하고 테스트 이벤트를 보내야 합니다. 연동 설정만 저장한 것을 이벤트 수신 성공으로 판단하지 마세요.

## 확인하고 수정하기

자동화 목록에서 항목을 열어 조건, 할 일, 보고 위치를 확인하세요. 권한이 있으면 켜기·끄기 또는 삭제를 할 수 있습니다. **일정 자동화의 변경은 채팅에서 Agent에게 요청**하세요. 메시지·웹훅 자동화는 해당 상세 화면에서 제공하는 편집 항목을 사용합니다.

플레이북을 여러 자동화가 공유하면 저장 시 다른 자동화에도 영향을 줄 수 있습니다. 확인 화면에서 **이 자동화만 바꾸기**와 전체에 반영하는 선택을 구분하세요. 이 자동화만 바꾸는 선택은 플레이북 사본을 만들 권한이 필요합니다.

## 실행 결과 확인하기

목록과 상세에서 실행 대기·실행 중·완료·실행 실패·보고 실패 등의 상태를 확인하고, 결과 받을 방의 실제 응답도 확인하세요. **실행 실패와 보고 실패는 다릅니다.** 작업을 반복하기 전에 이미 실행된 내용이 있는지 확인하세요. 일시정지, 조건 불일치, 접근 권한 문제로 실행되지 않은 경우도 구분합니다.

더 이상 필요하지 않으면 자동화를 끄거나 삭제하세요. 삭제는 되돌릴 수 없으므로 조건과 필요한 결과를 먼저 확인합니다.

## 주기 점검과 Task의 차이

[HEARTBEAT.md](../guides/configure-heartbeat.mdx)는 Agent의 주기 점검 지침이고, [Tasks와 Milestone](../guides/use-tasks-and-milestones.mdx)은 업무 상태와 마감일을 관리합니다. 특정 시각에 작업을 실행하려면 일정 자동화를 설정하고 활성 상태를 확인하세요. 파일이나 마감일을 작성하는 것만으로 예약 실행이 등록되지는 않습니다.
