# 자동화와 Webhook

외부 서비스의 이벤트를 Agent 또는 Chat Room으로 전달하려면 Webhook을 사용합니다. 이벤트 출처, 전달 대상, 처리 지침을 설정하고 테스트 이벤트로 결과를 확인하세요.

## 필요한 구성

| 구성 | 역할 | 확인할 사항 |
| --- | --- | --- |
| Source | 이벤트를 보내는 출처 | 조직, 출처 유형, 서명 검증에 필요한 비밀값 |
| Rule | 이벤트를 받을 Agent 또는 Room | 같은 테넌트의 대상, 조건과 전달 제한 |
| Playbook | Agent에게 전달할 처리 지침 | 기대 결과, 허용한 작업과 데이터 범위 |
| Event | 수신·전달 기록 | 성공·실패 상태와 실제 대상의 응답 |

## 시작하고 결과 확인하기

[Webhook으로 Agent에게 이벤트 보내기](../guides/send-webhook-to-agent.mdx)의 준비물과 설정 순서를 따르세요. 비민감 데이터로 테스트한 뒤 Event 기록과 대상 Room에서 실제 전달을 확인합니다. 이벤트 수신 성공만으로 Agent의 업무 완료나 자동 재시도가 보장되지는 않습니다.

실패하면 Event 기록, 전달 대상, Agent 상태를 함께 확인합니다. 같은 이벤트를 다시 보내기 전에는 이미 실행된 작업이 있는지 확인하세요.

## 중지와 정리

Source 또는 Rule을 비활성화해 새 이벤트 처리를 중지할 수 있습니다. 삭제 전에는 연결된 서비스와 필요한 설정을 확인하고, 비밀값을 교체할 때는 보내는 서비스의 설정도 함께 갱신합니다.

## 주기 점검과 Task의 차이

[HEARTBEAT.md](../guides/configure-heartbeat.mdx)는 주기 점검을 사용하는 Agent의 점검 지침입니다. [Tasks와 Milestone](../guides/use-tasks-and-milestones.mdx)은 업무 상태와 마감일을 관리합니다. 파일이나 마감일을 작성하는 것만으로 특정 시각의 자동 실행을 설정한 것은 아닙니다.
