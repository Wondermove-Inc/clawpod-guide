# ClawPod 기능 안내

업무 목표에 맞는 가이드를 선택하세요. 각 가이드에서 사용 위치, 필요한 권한과 설정, 정상 결과를 확인할 수 있습니다. 문서에 설명된 기능도 조직 설정과 실행 중인 Agent 상태에 따라 사용 범위가 달라집니다.

## Portal에서 사용하는 기능

| 하고 싶은 일 | 필요한 조건 | 사용 가이드 |
| --- | --- | --- |
| Agent 만들기·상태 확인·관리 | Agent 생성·관리 권한, 사용 가능한 한도 | [Agent 생성](../guides/create-agent.mdx), [Agent 관리](../guides/manage-agent.mdx) |
| Agent와 대화하고 파일 받기 | 해당 조직과 Room 접근 권한 | [Chat Room](../guides/use-chat-room.mdx), [파일 형식과 결과물](../guides/file-formats-and-artifacts.mdx) |
| 개인 AI 대화와 검색 사용 | AI Chat 접근과 사용 가능한 모델 | [AI Chat](../guides/use-ai-chat.mdx) |
| 이전 대화 찾기 | 해당 Room 기록 접근 권한 | [Chat Archive](../guides/use-chat-archive.mdx) |
| 업무와 마일스톤 추적 | 대상 조직 접근 권한 | [Tasks와 Milestone](../guides/use-tasks-and-milestones.mdx) |
| 회의 전사·요약 관리 | 회의 기능 접근, 녹음 대상의 동의와 조직 정책 | [회의록](../guides/use-meeting-minutes.mdx) |
| AI 연결과 모델 관리 | AI 키·Agent 관리 권한 | [AI 키 관리](../guides/manage-credentials.mdx), [모델 선택](../guides/select-models.mdx) |
| Skill 찾기·설치 요청·상태 확인 | Skill 사용·설치 권한, 대상 Agent | [Skill Marketplace](../guides/manage-skills.mdx) |
| Agent 지침과 템플릿 관리 | Agent 또는 템플릿 관리 권한 | [지침 설정](../guides/configure-agent-workspace-files.mdx), [템플릿](../guides/use-agent-templates.mdx) |
| 외부 이벤트로 Agent 호출 | Webhook 권한, 이벤트 출처와 대상 설정 | [Webhook](../guides/send-webhook-to-agent.mdx) |
| 멤버·조직·접근 권한 관리 | 조직·사용자·정책 관리 권한 | [조직 관리](../guides/manage-organization.mdx), [IAM](../guides/manage-iam.mdx) |
| 활동·비용·구독 확인 | 해당 Agent 및 결제 정보 접근 권한 | [Analytics](../guides/use-analytics.mdx), [Billing](../guides/manage-billing.mdx) |
| 계정 보안·알림·감사 기록 관리 | 본인 계정 또는 감사 기록 조회 권한 | [계정 보안](../guides/secure-your-account.mdx), [알림](../guides/manage-notifications.mdx), [Audit Log](../guides/use-audit-log.mdx) |

## Agent에게 요청하는 작업

| 작업 | 먼저 확인할 조건 | 사용 가이드 |
| --- | --- | --- |
| 파일 읽기·쓰기, 스크립트와 코딩 | 대상 파일 접근 권한, 필요한 도구, 허용한 변경 범위 | [Browser와 CLI 작업 요청](../guides/use-browser-and-cli.mdx) |
| 브라우저 탐색·입력·화면 확인 | 브라우저를 사용할 수 있는 Agent, 대상 사이트 접근 | [Browser와 웹 작업](./browser-and-web.mdx) |
| 원격 화면 확인과 데스크톱 작업 | 데스크톱을 지원하는 실행 중인 Agent | [Agent Desktop](../guides/use-agent-desktop.mdx) |
| 기억할 내용 저장·활용 | Agent의 기억 기능 준비 상태와 조직 보존 정책 | [Memory와 Agent 설정](./memory-and-configuration.mdx) |
| 이미지 생성·음성 전사 | 해당 Agent의 OpenAI 연결, 필요한 도구, 입력 권한과 비용 범위 | [이미지와 음성 작업](./channels-and-media.mdx) |

작업을 맡길 때 대상, 원하는 결과, 허용한 변경과 외부 전송 범위를 함께 적으세요. 실행 가능 여부를 확인할 수 없으면 Agent가 그 상태를 설명하도록 합니다. [기능 사용 조건](./consumer-availability.mdx)을 참고하세요.
