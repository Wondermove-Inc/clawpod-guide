## Optional integration 확인

| 기능 | 상태 | 활성화 조건 |
| --- | --- | --- |
| 여러 message channel 연결 | runtime adapter 확인 | channel 계정·pairing·allowlist·조직 승인 |
| model provider와 fallback | runtime adapter 확인 | provider credential·지원 release |
| Image generation·edit | runtime adapter 확인 | provider 연결·비용·입력 정책 |
| Video·music generation | runtime adapter 확인 | provider 연결·비동기 task delivery |
| Text-to-speech·media 이해 | runtime adapter 확인 | media provider·auto 설정 |
| Web search provider | Cloud wrapper binding 미확인 | Portal AI Chat 검색과 별개이며, Agent용 consumer credential·binding 경로 없음 |
| Node·device pairing | runtime adapter 확인 | device owner 승인·scope·연결 해제 |
| Voice call | runtime adapter 확인 | telephony provider·plugin·운영자 설정 |
| Plugin 설치 | runtime adapter 확인 | 호환 package·restart·최소 권한 |

패키징·API key 조건·Cloud 미확인 capability의 세부 상태는 [Runtime capability 활성화 상태](/capabilities/runtime-availability)에서 확인합니다.

`runtime 확인` 항목은 [소비자 제공 상태](/capabilities/consumer-availability)에서 “Agent에게 요청” 또는 “소비자 제공 경로 없음”으로 다시 구분합니다. 후자 항목은 현재 고객 기능이 아닙니다.

## 현재 소비자 기능이 아닌 항목

| 항목 | 상태 | 안내 |
| --- | --- | --- |
| API Keys settings | retired | Portal 경로는 홈으로 redirect되며, 소비자용 API key 생성 기능으로 안내하지 않습니다. |
| IAM Group·reusable Role 관리 | API source만 확인 | 현재 Portal의 고객 관리 흐름은 사용자 직접 Policy이며, Group·reusable Role은 고객 관리 기능이 아닙니다. |
| Dreaming | removed | 현재 Agent의 memory 기능으로 대체되며, Dreaming 설정·주기 기능을 안내하지 않습니다. |
| Legacy Workflow route | unsupported | route가 남아 있어도 인증·RBAC·tenant 경계가 소비자 기능으로 확인되지 않았습니다. 고객·플랫폼 최고 관리자 사용 절차로 안내하지 않습니다. |
