# 계정과 조직 관리

조직 관리 기능은 내 역할, 해당 조직의 권한, 요금제와 사용량 한도에 따라 달라집니다. 메뉴가 보이지 않으면 먼저 조직과 계정이 맞는지 확인하세요.

| 관리할 내용 | 할 수 있는 일 | 상세 가이드 |
| --- | --- | --- |
| 조직과 멤버 | 조직 생성, 사용자·Agent 연결, 멤버 관리 | [조직 관리](../guides/manage-organization.mdx) |
| 접근 권한 | 사용자에게 필요한 Policy 연결, 유효 권한 확인 | [IAM](../guides/manage-iam.mdx) |
| 계정 보안 | 비밀번호와 MFA 관리 | [계정 보안](../guides/secure-your-account.mdx) |
| 알림 | 알림 종류와 전달 방식 선택 | [알림 설정](../guides/manage-notifications.mdx) |
| 감사 기록 | 허용된 범위의 변경 기록 조회·내보내기 | [Audit Log](../guides/use-audit-log.mdx) |
| 활동과 비용 | 접근 가능한 Agent의 활동·대화·비용 확인 | [Analytics](../guides/use-analytics.mdx), [Dashboard와 Costs](../guides/use-dashboard-and-costs.mdx) |
| 구독과 한도 | 구독 상태, 변경·취소 절차와 사용량 확인 | [Billing](../guides/manage-billing.mdx), [Workspace 사용량](../guides/check-workspace-and-system.mdx) |

## 변경 전후 확인하기

변경할 조직과 대상 사용자·Agent를 확인하고 필요한 권한만 부여합니다. 멤버 제거, 연결 해제, 구독 변경은 기존 접근과 업무에 영향을 줄 수 있으므로 각 가이드의 조건과 결과를 확인하세요.

오류가 나면 권한을 넓히기 전에 대상, 사용량 한도와 오류 내용을 먼저 확인합니다. 플랫폼 전체 설정과 운영 복구는 공개 조직 사용자 가이드의 범위에 포함하지 않습니다.
