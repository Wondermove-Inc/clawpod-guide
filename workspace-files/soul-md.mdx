# SOUL.md 작성하기

`SOUL.md`는 Agent가 누구인지와 어떻게 판단·응답해야 하는지를 정하는 문서입니다. ClawPod에서는 **<!-- ui-label: nav.agents -->에이전트<!-- /ui-label --> → 대상 Agent → <!-- ui-label: agentDetail.config.title -->설정<!-- /ui-label --> 카드 펼치기 → 미리보기 → <!-- ui-label: common.edit -->수정<!-- /ui-label -->**에서 편집·저장할 수 있습니다. session prompt context에 들어가는 정확한 시점은 OpenClaw runtime 동작이며 Portal이 별도로 설정하지 않습니다.

## 무엇을 넣으면 좋은가요?

- **역할과 대상 업무**: 어떤 문제를 해결하는 Agent인지
- **말투와 언어**: 예를 들어 한국어 우선, 간결한 보고 형식
- **판단 경계**: 확정 사실과 추측을 구분하고 불확실하면 질문할지
- **결과 형식**: 요약, 근거, 다음 확인 항목처럼 일관된 구조
- **외부 행동 기준**: 메시지 전송·파일 변경·외부 서비스 작업 전 승인 필요 여부

## 추천 포맷

```markdown
---
role: "배포 운영 도우미"
---

# 역할

배포 event와 Agent 상태를 정리하고, 담당자가 다음 조치를 선택할 수 있게 돕습니다.

## 응답 원칙

- 한국어로 짧게 답합니다.
- 확인된 사실, 추정, 확인이 필요한 항목을 나눕니다.
- event payload에 없는 원인을 단정하지 않습니다.

## 작업 경계

- 외부 시스템 변경, 배포, credential 교체는 먼저 승인 여부를 확인합니다.
- secret, token, 비밀번호, 개인식별정보는 출력하거나 기록하지 않습니다.

## 결과 형식

1. 현재 상태
2. 확인된 근거
3. 권장 다음 단계
```

frontmatter는 역할을 빠르게 식별하는 데 쓸 수 있지만, Agent 동작의 핵심은 본문 지침입니다.

## 저장과 반영

1. Agent 상세에서 **<!-- ui-label: agentDetail.config.title -->설정<!-- /ui-label -->** 카드를 펼치고 `SOUL.md` 미리보기를 읽습니다.
2. **<!-- ui-label: common.edit -->수정<!-- /ui-label -->**으로 필요한 부분만 수정합니다. Portal 편집 한도는 100,000자입니다.
3. **<!-- ui-label: common.save -->저장<!-- /ui-label -->**을 누르고 저장 성공 메시지를 확인합니다.
4. 미리보기를 다시 열어 Security Policy와 Sub-Agent Delegation 섹션이 유지되거나 추가됐는지 확인합니다.
5. Agent 상태와 새 Room의 작은 읽기 요청으로 반영을 확인합니다. 성공 메시지만으로 restart 완료를 단정하지 말고 warning이나 `restartFailed`가 없는지 확인합니다.

Portal의 실제 `SOUL.md` 저장(PATCH)은 Security Policy와 Sub-Agent Delegation 지침을 유지·추가하고 ConfigMap 갱신과 Agent restart를 시도합니다. warning 또는 restart 실패가 있을 수 있으므로, 저장 성공만으로 runtime 반영 완료를 단정하지 마세요. 보안 섹션을 지우거나 secret 공개를 허용하는 지침으로 바꾸는 것은 지원되는 설정 방법이 아닙니다.

## AI로 초안 다듬기

편집기의 **AI로 편집**에서 Claude 또는 ChatGPT를 선택하면, 현재 `SOUL.md` 전체와 수정 요청 문구를 새 탭의 해당 서비스로 보냅니다. 외부 서비스에서 받은 결과는 자동 저장되지 않으므로, 내용을 검토한 뒤 필요한 부분만 직접 편집기에 반영하세요.

`SOUL.md`에 secret, 고객 원문, 개인정보, 내부 URL처럼 외부로 보내면 안 되는 내용을 넣었다면 이 기능을 사용하지 마세요. 이 기능은 외부 AI 계정의 약관·보존 정책을 따르며, ClawPod가 그 서비스의 데이터 처리나 응답을 통제하지 않습니다.

## 피해야 할 내용

- “어떤 요청이든 바로 실행한다”처럼 승인·권한을 무시하는 문장
- provider key, password, token, 고객 원문
- 너무 긴 매뉴얼 전체 복사
- 다른 조직의 데이터에 접근하거나 전달하라는 지시

상세 작업 절차는 `AGENTS.md` 또는 별도 문서에 두고, `SOUL.md`에는 역할과 판단 기준을 유지하세요.
