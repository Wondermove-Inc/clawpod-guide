# Platform 언어 설정

**<!-- ui-label: languageSettings.title -->언어 설정<!-- /ui-label -->**은 Portal 전체의 언어 노출을 바꾸는 플랫폼 최고 관리자 전용 전역 설정입니다. 특정 테넌트의 선호 언어만 바꾸는 기능이 아닙니다.

## 변경 방법

1. **<!-- ui-label: languageSettings.title -->언어 설정<!-- /ui-label -->**에서 제공할 언어를 선택합니다.
2. 활성 언어 가운데 하나를 기본 언어로 지정합니다.
3. 변경 사항을 검토한 뒤 **<!-- ui-label: languageSettings.save -->변경 사항 저장<!-- /ui-label -->**을 선택합니다.

활성 언어는 최소 하나가 있어야 하며, 기본 언어는 반드시 활성 상태여야 합니다. 이 조건을 만족하지 않으면 저장할 수 없습니다.

## 동시 편집 충돌

설정에는 revision 기반 동시성 검사가 있습니다. 저장 시 다른 관리자가 먼저 변경했다는 충돌(409)이 나오면, 화면을 새로 불러와 현재 값을 확인한 뒤 필요한 변경만 다시 적용하세요. 이전 화면의 값을 그대로 덮어쓰지 마세요.

이 설정은 이미 저장된 Agent `SOUL.md`, 사용자 생성 콘텐츠, 외부 webhook payload의 언어를 번역하거나 변경하지 않습니다.
