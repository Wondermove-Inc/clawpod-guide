# Portal 메뉴 노출 관리

**<!-- ui-label: menuVisibility.title -->메뉴 노출 관리<!-- /ui-label -->**는 Portal sidebar의 메뉴 노출을 전역적으로 관리하는 플랫폼 최고 관리자 전용 설정입니다. 숨긴 메뉴는 사용자가 탐색하기 어려워지므로, 지원·운영 안내와 함께 변경하세요.

## 안전한 변경 절차

1. 메뉴별 노출 상태를 초안으로 조정합니다.
2. 영향을 받는 사용자 역할과 현재 운영 절차를 검토합니다.
3. **<!-- ui-label: menuVisibility.save -->변경사항 저장<!-- /ui-label -->**으로 전체 변경을 한 번에 적용합니다.
4. 일반 사용자 계정으로 sidebar 표시를 확인합니다.

화면은 초안 편집 후 전체 설정을 원자적으로 저장합니다. 저장 충돌(409)이 발생하면 최신 설정을 다시 불러오고, 다른 관리자의 변경을 확인한 뒤 재적용하세요.

## 중요한 경계

메뉴 숨김은 **탐색 UI의 노출 제어**입니다. 이를 IAM 권한 회수나 backend 접근 차단으로 취급하지 마세요. 실제 작업 가능 여부는 Policy, role, tenant·organization scope가 계속 결정합니다. 민감 기능을 차단하려면 [IAM, Policy, Role 관리](/guides/manage-iam)에서 권한을 별도로 조정해야 합니다.
