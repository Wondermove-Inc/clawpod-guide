# 파일 형식과 Agent artifact

“업로드할 수 있다”, “Portal에서 미리보기할 수 있다”, “Agent가 만들 수 있다”는 서로 다른 말입니다. 아래 표는 Chat·Task 첨부의 형식과 제한을 설명합니다.

## Chat 첨부: 업로드 가능 형식

Chat Room 첨부는 파일당 최대 **50 MiB**(화면 표기 50 MB)입니다. 다음 확장자를 지원합니다.

| 범주 | 허용 확장자 | Portal 미리보기 |
| --- | --- | --- |
| 이미지 | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.bmp` | 이미지 미리보기. 브라우저가 표시하지 못하면 다운로드합니다. |
| 문서 | `.pdf`, `.docx`, `.xlsx`, `.pptx`, `.hwp`, `.hwpx` | PDF는 최대 **10 MiB**까지 미리보기. 나머지는 다운로드합니다. |
| 텍스트 | `.txt`, `.text`, `.csv`, `.md`, `.markdown`, `.env`, `.log`, `.ini`, `.conf`, `.cfg`, `.properties` | 텍스트 미리보기. 1 MiB를 넘으면 앞부분 256 KiB만 표시됩니다. |
| 데이터·설정 | `.json`, `.jsonl`, `.yaml`, `.yml`, `.toml` | 다운로드 |
| HTML | `.html`, `.htm` | 다운로드. Chat 첨부의 HTML 실행·미리보기는 제공하지 않습니다. |
| 동영상 | `.mp4` | 다운로드. Portal 내 재생은 제공하지 않습니다. |
| 압축 파일 | `.zip` | 다운로드 |

`.env`와 `.env.production` 같은 환경 설정 파일명도 인식합니다. 업로드 형식으로 허용된다는 뜻이지 비밀값을 공유해도 된다는 뜻은 아닙니다. API key·비밀번호가 포함된 설정 파일은 값을 제거한 사본을 사용하고, 실제 비밀값은 [시크릿 안내](./handle-secrets.mdx)를 따르세요.

지원 확장자는 대소문자를 구분하지 않으며, 브라우저가 MIME type을 비우거나 다르게 보내도 확장자에 맞춰 정규화합니다. 그 밖의 파일은 기존 허용 MIME type에 해당할 때 업로드될 수 있습니다. `.svg`, `.svgz`, `.js`, `.mjs`, `.cjs`, `.exe`, `.msi`, `.com`, `.bat`, `.cmd`, `.ps1`, `.sh`는 MIME type과 무관하게 차단합니다. 확장자 변경은 파일 변환이나 안전성 검증이 아닙니다.

## Task·Milestone 첨부

Task·Milestone은 파일당 최대 **50 MiB**이며 Chat의 확장된 형식 목록과 별도입니다. 기존 MIME 허용 목록인 JPEG·PNG·GIF·WebP·BMP, PDF·DOCX·XLSX·PPTX, TXT·CSV·Markdown, HWP·HWPX, ZIP을 사용합니다. Chat에서 허용하는 HTML·MP4·JSON·YAML 등의 추가 형식을 Task·Milestone에서도 지원한다고 해석하지 마세요.

## 미리보기와 다운로드의 경계

- **텍스트 미리보기**: 저장 MIME type이 `text/plain`, `text/csv`, `text/markdown`인 파일에 제공됩니다. 1 MiB 초과 파일은 앞부분 256 KiB만 표시합니다.
- **PDF 미리보기**: 10 MiB 이하에 제공됩니다.
- **이미지 미리보기**: 허용된 이미지 형식에 제공됩니다.
- **그 밖의 허용 형식**: 다운로드해 확인합니다. HTML 첨부는 아래의 HTML artifact 미리보기와 별도입니다.

미리보기는 안전성 검사나 완전한 파일 검증이 아닙니다. 외부에서 받은 ZIP, Office 문서, 이미지에는 악성 내용이 포함될 수 있으므로, 실행하거나 외부 공유하기 전에 조직의 보안 절차를 따르세요.

## Agent가 만들 수 있는 결과물

| 결과물 | 현재 확인된 경로 | 주의점 |
| --- | --- | --- |
| Chat artifact | Markdown 또는 HTML download UI | Agent가 artifact 형태로 응답한 경우에만 제공합니다. |
| Meeting 결과 | text 또는 Markdown download UI | 회의 기능과 artifact 생성 조건이 충족될 때만 제공합니다. |
| Workspace 파일 | Agent의 file/CLI 도구가 실제 ready일 때 생성 가능 | 형식은 요청한 도구·image·policy에 따라 달라지며, 모든 확장자를 보장하지 않습니다. |
| 생성 이미지 | OpenAI key와 image-generation runtime이 준비된 경우 | output MIME type·저장 위치·비용은 실행 결과에서 확인합니다. |

PDF, DOCX, XLSX, PPTX, ZIP 같은 결과물을 Agent에게 요청할 수는 있지만, 해당 형식의 생성 도구가 selected image·Skill·runtime에 실제 있는지 먼저 확인해야 합니다. 단순히 Chat이 그 파일을 받아준다는 사실은 Agent가 만들 수 있다는 보장이 아닙니다.

## Chat artifact 열기와 내려받기

Chat message에 artifact card가 보이면 card를 눌러 Artifact panel을 엽니다. panel은 해당 artifact의 정확한 version을 불러오며, 여러 version이 있으면 원하는 version을 선택할 수 있습니다.

- Markdown과 HTML 내용을 preview합니다.
- Markdown 또는 일반 text를 clipboard에 복사합니다.
- HTML artifact는 `.html`로, 그 밖의 artifact는 `.md`로 내려받습니다.

artifact를 열 권한이 없으면 forbidden으로, 해당 version이 없으면 not found로 표시됩니다. artifact는 대화에서 생성된 versioned 결과물이며 Agent workspace 파일과 자동으로 동기화되지 않습니다.
