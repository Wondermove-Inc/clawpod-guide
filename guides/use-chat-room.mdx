# Chat Room에서 Agent와 협업하기

Chat Room은 사용자와 Agent가 같은 대화 맥락에서 협업하는 공간입니다. Room 접근 범위와 참가자는 조직 권한에 따라 제한됩니다.

## 1. Room 준비하기

1. Portal에서 **<!-- ui-label: modeToggle.chat -->채팅<!-- /ui-label -->**을 엽니다.
2. 왼쪽 sidebar의 Room 생성 동작을 선택하거나 기존 Room을 선택합니다.
3. 새 Room이면 이름과 참가자를 정한 뒤 생성합니다. 참가자 선택 범위는 현재 권한에 따라 달라질 수 있습니다.
4. 새 Room이 선택됐는지 확인하고, 작업할 사용자와 Agent가 참가자로 보이는지 확인합니다.
5. compose 영역에 메시지를 입력하고, 의도를 분명히 해야 하면 mention 제안에서 Agent를 선택한 뒤 **<!-- ui-label: chat.send -->전송<!-- /ui-label -->**을 선택합니다.

Room 메시지는 참가 Agent 모두가 받을 수 있고 처리할 수 있습니다. mention은 특정 Agent만으로의 독점 routing이 아니라 의도를 분명히 하는 보조 수단입니다. 정확히 한 Agent만 작업해야 한다면 그 Agent만 포함한 전용 Room을 사용하세요. webhook으로 전달된 event도 Room 메시지로 들어오므로, 자동화 전용 Room을 사람의 일반 대화와 분리하면 운영이 쉽습니다.

전송한 메시지가 Room에 나타나고, 의도한 Agent의 응답 또는 처리 상태가 나타나는지 확인하세요. 전송 자체가 작업 완료를 뜻하지는 않습니다. 응답 생성 중에 **<!-- ui-label: aiChat.stopGenerating -->중지<!-- /ui-label -->**가 보이면 해당 응답만 중지할 수 있습니다.

## 2. 좋은 요청 작성하기

메시지에는 다음을 함께 적으세요.

- 원하는 결과물과 완료 기준
- 사용할 수 있는 자료 또는 첨부 파일
- 지켜야 할 제약과 금지 사항
- 불확실할 때 질문해야 하는지, 가정해도 되는지

예: “@배포도우미 오늘 배포 실패 event를 요약해 주세요. 확정된 사실과 확인이 필요한 항목을 나누고, secret 값은 출력하지 마세요.”

## 3. 파일과 결과물 다루기

Room에서는 허용된 형식과 크기 범위에서 파일을 첨부할 수 있습니다. 업로드 전에 개인정보, secret, 고객 데이터가 들어 있는지 확인하세요. 파일을 올렸다고 해서 Agent가 자동으로 외부에 전송하거나 영구 보관해야 한다는 의미는 아닙니다.

Agent가 만든 산출물은 대화 내용과 분리해 확인하고, 중요한 파일은 조직의 승인된 저장소에 보관하세요.

## 4. 음성 입력

1. Room의 compose 영역 왼쪽에서 마이크를 선택해 **<!-- ui-label: chat.voice.startDictation -->음성 입력 시작<!-- /ui-label -->**을 시작합니다.
2. 브라우저가 마이크 권한을 요청하면, 회의 녹음과 별개로 현재 입력을 받아쓰는 데 필요한 권한임을 확인한 뒤 허용합니다.
3. 말한 내용이 compose 영역에 들어오면 마이크를 다시 선택해 **<!-- ui-label: chat.voice.stopDictation -->음성 입력 중지<!-- /ui-label -->**를 선택합니다.
4. 전송 전에 변환된 텍스트와 Agent mention을 검토하고 **<!-- ui-label: chat.send -->전송<!-- /ui-label -->**을 선택합니다.

음성 입력 중에는 compose 영역이 편집 잠금 상태가 됩니다. 받아쓰기 중 말한 `@Agent`는 mention 선택창을 자동으로 열지 않으므로, 중지한 뒤 올바른 Agent가 mention됐는지 직접 확인하세요. 마이크 권한, 네트워크, 음성 세션 오류가 표시되면 전송을 반복하지 말고 권한·연결을 정리한 뒤 다시 시작합니다.

## 5. 회의 기능

Portal의 회의 기능은 녹음 동의, 전사, 요약, 회의록 폐기까지 포함합니다. 사용 절차와 개인정보 경계는 [회의록 만들기와 관리](/guides/use-meeting-minutes)를 따르세요.

## 6. Room 정리

Room 삭제는 기록 접근에 영향을 줄 수 있습니다. 삭제 전 필요한 결과물과 결정 사항을 보존하고, 자동화가 이 Room을 대상으로 삼고 있지 않은지 확인하세요. 더 이상 알림이 필요 없으면 Room 알림 설정을 조정할 수 있습니다.

## 7. 메시지 찾기

Room에서 **<!-- ui-label: chatSearch.openButtonLabel -->메시지 검색<!-- /ui-label -->**을 열거나 `Cmd+F`/`Ctrl+F`를 누르고 검색어를 입력합니다. 검색은 현재 불러온 메시지에만 적용되므로, 오래된 메시지를 찾을 때는 먼저 위로 스크롤해 기록을 더 불러오세요. 검색을 열면 Artifact panel이 닫힐 수 있습니다.
