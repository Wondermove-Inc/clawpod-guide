# 사용량과 Agent 상태 확인

## 사용량 확인

1. 상단 **관리자**를 선택하고 **대시보드**를 엽니다.
2. **워크스페이스 사용량**에서 현재 플랜과 멤버·조직·에이전트 수 및 한도를 확인합니다.
3. 구독 관리 권한이 있으면 **플랫폼 → 요금제 관리**를 엽니다. 결제 관리 화면의 **리소스 사용 현황**에서도 조직·사용자·에이전트 사용량을 확인할 수 있습니다.

사용량은 테넌트의 리소스 수입니다. Agent가 파일을 사용하는 작업 공간과는 다릅니다. 설정에서 별도 Workspace 메뉴를 찾을 필요가 없습니다.

한도에 도달해 생성이 거부되면 필요한 리소스 수와 현재 한도를 확인하고 테넌트 관리자와 정리 또는 [요금제 변경](./manage-billing.mdx)을 검토하세요.

## Agent가 응답하지 않을 때

1. **관리 → 에이전트**에서 대상의 상태를 확인합니다.
2. **상세 보기**에서 표시되는 지표와 로그를 확인합니다.
3. 웹훅으로 보낸 요청이면 **연동 → 웹훅 → 이벤트**에서 처리 기록을 확인합니다.
4. 여러 Agent에 같은 문제가 있으면 발생 시간과 영향 범위를 정리해 운영 담당자에게 전달합니다.

System·Monitoring은 이 고객용 점검 절차에 필요한 메뉴가 아닙니다. 화면에 없는 메뉴를 찾거나 주소를 추측하지 마세요.

## 메뉴가 보이지 않을 때

대시보드·에이전트·요금제 관리는 계정 역할과 허용된 메뉴에 따라 표시됩니다. 보이지 않으면 [Portal 메뉴 안내](../help/portal-feature-map.mdx)를 확인하고 테넌트 관리자에게 필요한 사용량이나 상태 확인을 요청하세요.
