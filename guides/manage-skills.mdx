# 스킬 찾기와 Agent 설치 관리

관리자 화면의 **스토어 → 스킬 라이브러리**에서 사용할 스킬을 찾고 Agent에 추가할 수 있습니다. 메뉴 열람, Agent 조회·변경, 비공개 스킬 관리에는 각각 권한이 필요합니다. 스킬을 볼 수 있어도 설치할 수 없는 경우가 있습니다.

## 스킬 찾아 설치하기

1. 스킬 라이브러리에서 이름으로 검색하고 필요한 항목을 엽니다. 공식 스킬과 테넌트의 비공개 스킬을 구분해 확인하세요.
2. 설명과 제공되는 버전을 확인합니다. 여러 버전이 있으면 설치할 버전을 선택합니다.
3. 추가할 스킬과 대상 Agent를 선택합니다. 여러 스킬·Agent를 함께 선택해 일괄 설치할 수도 있습니다.
4. 이미 같은 스킬이 설치된 대상은 건너뛸지 재설치할지 정하고 설치를 진행합니다.
5. 대상별 결과와 Agent의 설치 현황을 확인합니다. 설치 요청 접수만으로 모든 대상의 설치가 완료된 것은 아닙니다.

내장 스킬이나 다른 출처의 같은 이름 스킬과 충돌하면 화면의 제한·오류를 확인하세요. 이름이 같다고 임의로 덮어쓰지 않습니다. 설치가 끝나도 외부 서비스 인증이 필요한 스킬은 별도 연결을 마쳐야 합니다. [Resend](./use-resend-email.mdx)와 [Google Workspace](./use-google-workspace.mdx) 연결 가이드를 참고하세요.

## 설치 현황·재설치·제거

Agent 상세의 **스킬** 영역에서 그 Agent의 설치 현황을 확인할 수 있습니다. 채팅방의 스킬 패널에서도 접근 가능한 참가 Agent의 스킬을 확인하고, 권한이 있으면 추가·재설치·제거할 수 있습니다.

- 확인 중이거나 오래된 정보, Agent 연결 실패는 “설치되지 않음”과 다릅니다. 상태를 새로 확인하고 오류를 해결하세요.
- 재설치할 때는 대상 Agent와 패키지·버전을 확인하세요.
- 제거는 해당 Agent의 스킬에 적용됩니다. 내장 스킬 등 제거할 수 없는 항목은 화면에서 제한됩니다.
- 스킬 제거가 외부 서비스 계정 해제나 API 키 폐기를 뜻하지는 않습니다.

## 일괄 설치 진행 확인

서버에 접수된 일괄 설치는 브라우저 탭을 닫아도 계속 진행됩니다. 같은 사용자·테넌트의 브라우저에서 설치 이력을 다시 열어 대상별 진행 상황을 확인하세요. 브라우저의 이력 정보가 지워지면 같은 방식으로 이력을 찾지 못할 수 있습니다.

성공·건너뜀·실패를 구분하고, 재시도가 가능한 실패 대상은 결과 화면에서 재시도합니다. 탭을 닫았다는 이유로 같은 설치를 새로 요청하지 마세요.

## 비공개 스킬 관리

권한이 있는 관리자는 테넌트에서 사용할 비공개 스킬을 업로드하고 버전을 관리할 수 있습니다.

1. 라이브러리의 비공개 스킬 업로드에서 `.zip` 또는 `.tar.gz` 패키지를 선택합니다.
2. 이름·버전·설명을 입력하고 화면의 패키지 검증 결과를 확인합니다.
3. 기존 스킬의 새 버전이라면 해당 스킬의 버전 추가 기능을 사용합니다. 기본 버전을 바꿔도 이미 설치된 모든 Agent가 자동 갱신된다고 가정하지 마세요.
4. 더 이상 배포하지 않을 스킬은 보관하고, 필요하면 보관 목록에서 복원합니다. 보관과 Agent에서의 제거는 별도로 확인하세요.

패키지에는 API 키나 비밀번호를 넣지 않습니다. 스킬의 작업 지침은 도구·계정 권한을 새로 부여하지 않으며, [현재 사용 가능한 도구](../capabilities/skills-and-tools.mdx)와 연결 상태도 함께 확인하세요.
