# 이전 대화 찾기

## 채팅방 찾기

1. 상단 **채팅**을 선택합니다.
2. 왼쪽 **채팅방 검색**에 찾을 채팅방 이름을 입력합니다.
3. 최근 목록에 원하는 방이 없고 **전체 보기**가 표시되면 목록을 펼칩니다.
4. 접근 가능한 채팅방을 선택해 기록을 확인합니다.

현재 안내는 별도의 Chat Archive 메뉴를 요구하지 않습니다. 보이지 않는 채팅방의 주소나 ID를 추측하지 마세요.

## 방 안에서 메시지 찾기

**찾기**를 열고 검색어를 입력합니다. 서버에 저장된 대화 기록에서 검색하므로 오래된 메시지를 먼저 불러올 필요가 없습니다. 결과를 선택하면 해당 메시지로 이동합니다. 자세한 사용법은 [Chat Room 안내](./use-chat-room.mdx)를 따릅니다.

채팅방 열기는 읽음 상태를 갱신할 수 있습니다. 기록 조회를 위해 방을 삭제하거나 참가자를 변경할 필요는 없습니다.
