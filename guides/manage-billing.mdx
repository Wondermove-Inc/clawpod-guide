# 요금제와 구독·결제 내역 확인

이 안내는 구독 관리 권한이 있는 테넌트 관리자를 위한 것입니다. 일반 사용자에게 메뉴가 보이지 않으면 담당 관리자에게 문의하세요.

## 결제 화면 열기

1. 상단 **관리자**를 선택합니다.
2. 사이드바 **플랫폼 → 요금제 관리**를 선택합니다.
3. 연결된 **결제 관리** 화면에서 현재 플랜·청구 정보와 **리소스 사용 현황**을 확인합니다.
4. 같은 화면 아래 **결제 내역**에서 날짜·플랜·결제 주기·변동·금액을 확인합니다. 필요한 항목에 **상세**가 표시되면 열어 확인합니다.

별도 사이드바의 결제 내역 메뉴를 찾을 필요가 없습니다. 플랫폼 전체 거래를 관리하는 화면과 테넌트의 구독 내역은 다릅니다. LLM 사용량에 따른 비용 분석은 [LLM 사용 비용](./use-analytics.mdx)을 참고하세요.

## 구독 변경 전 확인

Free·유료 여부, 결제 제공자와 현재 구독 상태에 따라 표시되는 버튼이 다릅니다. 현재 화면에 제공되는 플랜 업그레이드·요금제 조정·취소·재개 동작만 사용하세요. 버튼이 없으면 청구 담당자에게 문의합니다.

변경 전 다음을 확인합니다.

- 대상 플랜, 월간·연간 결제 주기와 표시 금액
- 현재 사용자·조직·Agent 수와 변경 후 한도
- 적용일, 다음 청구일 또는 취소 효력일
- 업무 중인 Agent와 보존할 데이터에 미치는 영향

결제나 변경 확인 화면에서 내용을 다시 검토한 뒤 확정하고, 결제 관리로 돌아와 구독 상태와 한도에 반영됐는지 확인하세요. 취소 예약을 데이터 삭제나 즉시 종료와 같은 의미로 해석하지 마세요.

## 오류가 있을 때

오류 메시지가 있거나 청구·구독 상태가 예상과 다르면 반복 결제하지 말고 청구 담당자에게 문의하세요. 화면 금액과 실제 결제 결과를 확인하기 전에는 가이드의 예시나 Agent 답변을 청구 금액으로 사용하지 않습니다. 결제정보·인증정보를 채팅에 붙여 넣지 마세요.
