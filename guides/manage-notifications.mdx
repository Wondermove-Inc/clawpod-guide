# 알림 설정 관리

**<!-- ui-label: notifications.page.title -->알림<!-- /ui-label -->**에서는 알림 목록을 확인하고, 본인 계정의 전달 선호를 바꿀 수 있습니다. 이 설정은 다른 사용자의 설정이나 Agent의 실행 정책을 바꾸지 않습니다.

## 전달 방식 설정

1. Portal에서 **<!-- ui-label: notifications.page.title -->알림<!-- /ui-label -->**을 엽니다.
2. **<!-- ui-label: notifications.settings.inAppNotifications -->앱 내 알림<!-- /ui-label -->**을 켜거나 끕니다.
3. 지원되는 브라우저에서 **<!-- ui-label: notifications.settings.pushNotifications -->푸시 알림<!-- /ui-label -->**을 켜면 브라우저 권한 요청을 승인합니다.

Push는 브라우저와 현재 origin의 권한에 의존합니다. 다른 브라우저·기기에서는 별도로 허용해야 하며, 브라우저 권한을 거절했거나 환경이 지원하지 않으면 토글을 켤 수 없습니다. 문제가 있으면 운영체제 알림 차단과 브라우저 사이트 권한도 함께 확인하세요.

## 알림 유형 설정

관리자 역할에는 message, Agent error·lifecycle, security, system, Skill, usage 같은 추가 유형이 표시될 수 있습니다. 테넌트 관리자는 member 관련 유형을 볼 수 있으며, 일반 멤버는 message 알림만 표시될 수 있습니다. 화면에 표시되는 유형만 본인에게 켜거나 끌 수 있습니다.

중요한 Agent 오류나 보안 알림을 끄기 전에는 대체 감시 경로가 있는지 확인하세요. 이 선호를 끄더라도 Agent, task, webhook의 원본 이벤트·실행 기록을 삭제하지는 않습니다.

## 알림 기록 확인

1. 알림 목록에서 제공되는 유형·심각도 필터를 적용합니다.
2. 항목을 열어 연결된 대상이 맞는지 확인합니다.
3. 개별 또는 전체 읽음 처리를 선택합니다.

현재 Portal 알림 목록에는 삭제 버튼이 없습니다. 읽음 처리는 연결된 Room, task, Agent, webhook의 원본 데이터를 바꾸지 않습니다.
