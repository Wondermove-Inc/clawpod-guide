# 이전 AI Chat 안내

현재 확인한 고객 메뉴에는 별도의 **OpenClaw AI / AI Chat** 진입 항목이 없습니다. 이 문서는 해당 화면이 모든 사용자에게 제공된다고 안내하지 않습니다.

Agent와 대화하려면 상단 **채팅**을 선택하고 [Chat Room 안내](./use-chat-room.mdx)를 따르세요. 웹 작업은 대상 Agent의 도구와 권한을 확인한 뒤 [브라우저 작업](./use-browser-and-cli.mdx)으로 요청합니다.

메뉴가 없는 경우 내부 주소를 추측하거나 권한을 늘려 별도 화면을 열려고 하지 마세요. 이 문서는 기존 링크를 유지하기 위한 안내입니다.
