# 회의록 만들기와 관리

회의록은 Chat Room의 회의 기능에서 만듭니다. 녹음과 전사는 참가자 개인정보를 처리하므로, 시작 전에 조직의 보존 정책과 모든 참가자의 동의를 확보하세요.

## 1. 회의 시작

1. 회의를 진행할 Chat Room을 열고 **<!-- ui-label: chat.meeting.toggleLabel -->회의록<!-- /ui-label -->**을 선택합니다. Agent만 있는 Room에서는 회의 시작이 제한될 수 있습니다.
2. 녹음과 참가자 알림 동의를 모두 선택합니다. 새 회의는 Portal의 기본 제목으로 기록됩니다.
3. 필요하면 번역을 설정합니다. 현재 선택지는 번역 없음, 단방향 번역, 양방향 번역입니다.
4. 회의 시간을 15분, 30분, 60분 중 선택하고 **<!-- ui-label: chat.meeting.consentConfirm -->동의하고 시작<!-- /ui-label -->**을 선택합니다.

동의 항목을 모두 선택해야 시작할 수 있습니다. 동의가 없거나 녹음이 허용되지 않는 회의에서는 전사 기능을 사용하지 마세요.

## 2. 전사와 요약 확인

진행 중에는 Meeting panel에서 전사 내용을 읽고 문단을 정리할 수 있습니다. 회의를 끝내면 다음 중 하나를 선택합니다.

- **<!-- ui-label: chat.meeting.endDeliver -->에이전트에 전달<!-- /ui-label -->**: 전사를 저장하고 요약을 생성해 원문·요약 결과물을 Chat Room에 보냅니다.
- **<!-- ui-label: chat.meeting.endDiscard -->버리기<!-- /ui-label -->**: 회의록을 archive에서 제외하는 soft delete를 수행합니다.

회의가 시간 제한으로 끝나도 같은 선택을 합니다. 전사가 비어 있거나 저장되지 않으면 요약을 생성할 수 없으므로, 내용을 먼저 확인한 뒤 전달하세요. 완료 뒤에는 전달 또는 버리기 결과가 표시되는지 확인하세요.

## 3. 이전 회의록과 요약 버전

Chat Room의 회의 기록에서 이전 회의록을 열 수 있습니다. 확정된 회의록에서는 전사와 요약을 보고, 요약을 다시 생성할 수 있습니다. 재생성된 요약은 새 version으로 저장되므로 중요한 결정을 공유하기 전에는 현재 version인지 확인하세요.

회의 기록 panel에서는 전사를 `.txt` 또는 `.md`로 내려받을 수 있습니다. 필요한 원문·요약은 삭제 전에 내려받아 조직의 승인된 저장소에 보관하세요. 회의록을 삭제하면 삭제 사유가 기록되며, 대화에서 참조하던 결과물을 다시 열 수 없을 수 있습니다.

## 4. 요약 검증 실패와 수동 검토

회의 요약에 왜곡 또는 사실 오류가 감지되면 **<!-- ui-label: chat.meeting.validation.manualReviewRequired -->사람 검수가 필요합니다.<!-- /ui-label -->** 배너와 **<!-- ui-label: chat.meeting.validation.reviewCta -->수동 검토 시작<!-- /ui-label -->**이 표시됩니다. 이 버튼이 보이는 사용자는 다음 순서로 검토합니다.

1. 전사 원문과 요약의 결정사항·수치·담당자·기한을 대조합니다.
2. **<!-- ui-label: chat.meeting.validation.reviewCta -->수동 검토 시작<!-- /ui-label -->**을 선택합니다.
3. M8·M10·M11·M13은 0~5점, S3·S4는 0~3점으로 평가합니다.
4. **<!-- ui-label: chat.meeting.attestation.submit -->검토 제출<!-- /ui-label -->**을 선택합니다. 제출 뒤 검증이 다시 실행됩니다.

검토 점수는 요약 원문을 고치는 기능이 아닙니다. 요약에 문제가 있으면 원문을 근거로 재생성하거나 회의록을 정정하는 절차를 따르고, 점수만 높여 통과시키지 마세요.

## 5. 실패와 개인정보 처리

- 전사 또는 요약 처리 오류가 나면 오류 메시지와 회의 상태를 확인하고, 같은 회의를 여러 번 새로 만들지 마세요.
- 녹음 원본, 전사, 번역문, 요약에는 개인·고객 정보가 포함될 수 있습니다. Chat, webhook, 외부 도구로 옮길 때는 수신 범위와 보존 기간을 제한하세요.
- 회의 도메인 검증과 요약 quota 대시보드는 일반 회의록 사용 절차가 아닌 별도 운영 경계입니다. 수동 검토 시작 버튼이 실제로 표시될 때만 위 수동 검토 절차를 사용합니다.
