# 회의록 만들기와 관리

회의록은 Chat Room의 회의 기능에서 만듭니다. 녹음과 전사는 참가자 개인정보를 처리하므로, 시작 전에 조직의 보존 정책과 모든 참가자의 동의를 확보하세요.

## 1. 회의 준비와 녹음 시작

1. 회의를 진행할 Chat Room에서 **회의록** 도구를 열고 새 회의를 시작합니다. Agent만 있는 방이거나 필요한 권한이 없으면 시작할 수 없다는 안내가 표시됩니다.
2. 준비 화면에서 통역 사용 여부와 두 언어를 선택합니다. 필요하면 주제·전문 용어·배경 설명·번역 용어 매핑을 입력해 인식 설정을 준비합니다. 반복해서 쓸 설정은 프리셋으로 저장하거나 기존 프리셋을 선택할 수 있습니다.
3. 녹음 시작 버튼을 누르면 동의 창이 열립니다. 회의 시간과 녹음·참가자 알림 동의를 확인하고 **동의하고 시작**을 선택합니다.
4. 마이크 연결과 녹음 상태가 표시되는지 확인합니다. 준비 화면을 열거나 설정을 저장한 것만으로 녹음이 시작되지는 않습니다.

진행 중에는 일시 정지·재개를 사용할 수 있습니다. 동의가 없거나 녹음이 허용되지 않는 회의에서는 전사를 시작하지 마세요.

## 크게 보기와 실시간 번역 공유

준비 화면이나 진행 중 메뉴의 크게 보기 기능으로 별도 화면에 자막을 표시할 수 있습니다. 원문·번역 표시를 선택하고 필요한 크기로 조정합니다.

실시간 번역 공유에서 링크를 만들면 **링크를 아는 사람이 자막을 볼 수 있습니다.** 공유 전에 참가자의 동의와 전달 대상을 확인하세요. 회의 종료 시 공유 링크는 닫히며, 회의록 파일을 영구 공유하는 기능과는 다릅니다.

## 2. 전사와 요약 확인

진행 중에는 Meeting panel에서 전사 내용을 읽고 문단을 정리할 수 있습니다. 회의를 끝내면 다음 중 하나를 선택합니다.

- <strong><span data-ui-label="chat.meeting.endDeliver">에이전트에 전달</span></strong>: 전사를 저장하고 요약을 생성해 원문·요약 결과물을 Chat Room에 보냅니다.
- <strong><span data-ui-label="chat.meeting.endDiscard">버리기</span></strong>: 회의록을 archive에서 제외하는 soft delete를 수행합니다.

회의가 시간 제한으로 끝나도 같은 선택을 합니다. 전사가 비어 있거나 저장되지 않으면 요약을 생성할 수 없으므로, 내용을 먼저 확인한 뒤 전달하세요. 완료 뒤에는 전달 또는 버리기 결과가 표시되는지 확인하세요.

## 3. 이전 회의록과 요약 버전

Chat Room의 회의 기록에서 이전 회의록을 열 수 있습니다. 확정된 회의록에서는 전사와 요약을 보고, 요약을 다시 생성할 수 있습니다. 재생성된 요약은 새 version으로 저장되므로 중요한 결정을 공유하기 전에는 현재 version인지 확인하세요.

회의 기록 panel에서는 전사를 `.txt` 또는 `.md`로 내려받을 수 있습니다. 필요한 원문·요약은 삭제 전에 내려받아 조직의 승인된 저장소에 보관하세요. 회의록을 삭제하면 삭제 사유가 기록되며, 대화에서 참조하던 결과물을 다시 열 수 없을 수 있습니다.

회의 기록에서는 검색과 기간 조건으로 회의를 찾을 수 있습니다. 기록을 열면 요약과 전사를 전환해 보고, 권한이 있으면 제목·화자 정보를 수정하거나 삭제할 수 있습니다. 다운로드 메뉴에서 텍스트·Markdown을 선택하고, 수정·삭제 전에는 필요한 내용을 보관하세요.

## 4. 요약 검증 실패와 수동 검토

회의 요약에 왜곡 또는 사실 오류가 감지되면 <strong><span data-ui-label="chat.meeting.validation.manualReviewRequired">사람 검수가 필요합니다.</span></strong> 배너와 <strong><span data-ui-label="chat.meeting.validation.reviewCta">수동 검토 시작</span></strong>이 표시됩니다. 이 버튼이 보이는 사용자는 다음 순서로 검토합니다.

1. 전사 원문과 요약의 결정사항·수치·담당자·기한을 대조합니다.
2. <strong><span data-ui-label="chat.meeting.validation.reviewCta">수동 검토 시작</span></strong>을 선택합니다.
3. M8·M10·M11·M13은 0~5점, S3·S4는 0~3점으로 평가합니다.
4. <strong><span data-ui-label="chat.meeting.attestation.submit">검토 제출</span></strong>을 선택합니다. 제출 뒤 검증이 다시 실행됩니다.

검토 점수는 요약 원문을 고치는 기능이 아닙니다. 요약에 문제가 있으면 원문을 근거로 재생성하거나 회의록을 정정하는 절차를 따르고, 점수만 높여 통과시키지 마세요.

## 5. 실패와 개인정보 처리

- 전사 또는 요약 처리 오류가 나면 오류 메시지와 회의 상태를 확인하고, 같은 회의를 여러 번 새로 만들지 마세요.
- 녹음 원본, 전사, 번역문, 요약에는 개인·고객 정보가 포함될 수 있습니다. Chat, webhook, 외부 도구로 옮길 때는 수신 범위와 보존 기간을 제한하세요.
- 회의 도메인 검증과 요약 quota 대시보드는 일반 회의록 사용 절차가 아닌 별도 운영 경계입니다. 수동 검토 시작 버튼이 실제로 표시될 때만 위 수동 검토 절차를 사용합니다.
