# 테넌트 공지 관리

이 안내는 **공지 관리** 메뉴가 보이는 테넌트 관리자를 위한 것입니다. 공지 관리 권한이 없는 일반 사용자의 작업 단계가 아닙니다.

## 공지 작성

1. 상단 **관리자 → 플랫폼 → 공지 관리**를 엽니다.
2. **공지 생성**을 선택합니다.
3. 제목과 Markdown 내용을 작성합니다. 제목은 500자, 내용은 10,000자 이내로 입력합니다.
4. 시작일·종료일과 활성 여부를 확인합니다.
5. 필요한 경우 링크 URL을 입력합니다. 화면은 `/portal/` 또는 `https://`로 시작하는 링크를 안내합니다.
6. 대상 테넌트와 조직을 확인합니다. 본인에게 허용된 테넌트 범위에서 전체 조직 또는 특정 조직을 선택합니다.
7. 내용·대상·표시 기간을 검토한 뒤 **공지 생성**을 선택합니다. 작성하지 않으려면 **취소**로 닫습니다.

목록의 전체·활성·예약됨 상태와 저장 결과를 확인하세요. 저장 오류가 표시되면 완료로 간주하지 않습니다. 특정 사용자에게 실제 표시됐는지는 해당 대상과 기간 조건도 확인해야 합니다.

화면 설명에 “플랫폼 전체”라는 문구가 있어도 테넌트 관리자의 범위가 다른 테넌트까지 확장되는 것은 아닙니다. 공지에는 비밀번호·인증 키·개인정보를 넣지 마세요.
