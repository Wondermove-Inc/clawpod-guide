# 계정·조직·알림 설정 관리

개인 설정은 본인 계정에 적용되고, 조직 설정과 멤버십 변경은 같은 조직의 다른 사용자와 Agent에 영향을 줄 수 있습니다. 변경 전 적용 범위를 확인하세요.

## 개인 계정 설정

Portal sidebar의 **<!-- ui-label: settings.title -->설정<!-- /ui-label -->**에서 다음 항목을 관리할 수 있습니다.

- **<!-- ui-label: settings.nav.profile -->프로필<!-- /ui-label -->**: 프로필과 비밀번호, MFA 관련 보안 설정
- **<!-- ui-label: settings.nav.appearance -->외관<!-- /ui-label -->**: Light, Dark, System 테마
- **<!-- ui-label: settings.nav.notifications -->알림<!-- /ui-label -->**: 알림 선호와 알림 목록

**<!-- ui-label: settings.nav.profile -->프로필<!-- /ui-label -->**, **<!-- ui-label: settings.nav.appearance -->외관<!-- /ui-label -->**, **<!-- ui-label: settings.nav.notifications -->알림<!-- /ui-label -->** 중 원하는 항목을 선택하고 변경한 뒤 **<!-- ui-label: common.save -->저장<!-- /ui-label -->**이 표시되는 화면에서는 저장 완료를 확인하세요. MFA 또는 비밀번호를 바꾼 뒤에는 현재 사용 중인 기기와 복구 수단을 확인하세요. 알림을 끄기 전에 webhook 실패, task 변경처럼 놓치면 안 되는 알림이 무엇인지 팀과 합의하는 것이 좋습니다.

## 조직과 멤버 관리

조직 관리 권한이 있으면 조직을 만들고, 사용자 또는 Agent 멤버십을 관리할 수 있습니다.

1. Portal의 조직 관리 화면에서 대상 조직을 엽니다.
2. 멤버와 Agent 목록, 현재 역할, 접근 범위를 확인합니다.
3. 필요한 최소 역할로 멤버를 추가하거나 역할을 변경합니다.
4. 제거 전에는 이 사용자가 소유한 Room, task, webhook 설정, Agent 운영 업무를 인계합니다.

조직 생성 가능 여부는 tenant quota와 plan에 따라 달라질 수 있습니다. 멤버를 제거하면 해당 조직의 데이터와 기능에 대한 접근이 사라질 수 있습니다.

## 알림 확인

알림 목록에서는 유형·심각도로 필터링하고 개별 또는 전체 알림을 읽음 처리할 수 있습니다. 개별 알림을 삭제하거나 읽은 알림을 비울 수도 있으며, 이 동작은 알림 상태만 바꾸고 원래의 Agent·task·webhook 데이터를 바꾸지 않습니다.

중요한 운영 알림은 읽음 처리하기 전에 연결된 Room, event, task의 원본 기록을 확인하세요.

## Tenant 탈퇴와 고위험 작업

테넌트 관리자에게는 tenant 탈퇴 흐름이 보일 수 있습니다. 이 작업은 관련 Agent 중지와 멤버 로그아웃을 유발할 수 있으므로, 데이터 보존·계약·복구 가능 기간을 확인하지 않은 상태에서 실행하면 안 됩니다.

테넌트 생성·복원·삭제, 요금제 목록·가격 변경, 플랫폼 언어 같은 전체 플랫폼 관리 기능은 플랫폼 최고 관리자 전용입니다. 일반 조직 운영의 범위를 넘으므로 별도 승인 절차와 관리자 가이드에 따라 처리하세요.
