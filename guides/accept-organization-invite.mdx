# 조직 초대 수락하기

초대 링크는 특정 이메일과 조직 멤버십에 연결됩니다. 링크를 전달하거나 다른 계정으로 수락하지 마세요.

## 초대 수락

1. 초대 이메일의 링크를 엽니다.
2. 링크에 표시된 조직, 초대한 사람, 부여될 역할을 확인합니다.
3. 초대받은 이메일과 같은 ClawPod 계정으로 로그인했는지 확인합니다.
4. **Accept**를 선택합니다.
5. Chat으로 이동한 뒤, 필요한 Room과 Agent 접근이 보이는지 확인합니다.

로그인한 계정의 이메일이 초대받은 이메일과 다르면 수락할 수 없습니다. 먼저 올바른 계정으로 로그인하세요.

## 만료·중복·오류

초대가 만료됐거나 이미 수락됐다면 새로 수락하지 말고 조직 관리자에게 상태를 확인합니다. 이메일 주소가 잘못됐거나 역할이 맞지 않으면 수락하지 말고 초대 취소·재발송을 요청하세요.

## 거절

**Decline**은 현재 수락 화면을 나가는 동작이며, 초대를 취소하거나 만료시키지 않습니다. 링크 노출이 의심되거나 참여하지 않으려면 조직 관리자에게 pending 초대 취소와 새 초대 발급을 요청하세요.
