# 웹사이트에 웹챗 위젯 설치하기

웹챗은 웹사이트에 채팅 버튼을 추가해 방문자가 ClawPod Agent와 대화할 수 있게 하는 기능입니다. Portal의 **웹챗** 메뉴에서 응답할 Agent와 연결할 사이트를 설정하고, 생성된 설치 코드를 사이트에 추가합니다.

## 준비하기

- 웹챗 메뉴와 풀·채널을 관리할 수 있는 권한
- 방문자에게 응답할 Agent
- 위젯을 설치할 사이트 주소와 사이트 코드를 수정·배포할 수 있는 권한

웹챗 메뉴는 관리자 화면에서 제공되며 역할·권한과 메뉴 노출 설정에 따라 보이지 않을 수 있습니다. 필요한 메뉴나 생성 버튼이 없다면 테넌트 관리자에게 문의하세요.

**조직에 소속된 Agent는 웹챗 풀에 추가할 수 없습니다.** 조직에 소속되지 않은 Agent를 준비하고, 방문자에게 응답할 내용과 사용할 자료를 점검하세요. Agent 준비는 [Agent 만들기](./create-agent.mdx)를 참고하세요.

## 1. 응답할 Agent 풀 만들기

풀은 웹챗 방문자에게 응답할 Agent를 묶어 관리하는 단위입니다.

1. Portal에서 **관리자 → 웹챗**을 엽니다.
2. **풀** 탭에서 **풀 생성**을 선택합니다.
3. 이름을 입력하고 **멤버**에서 응답할 Agent를 선택합니다.
4. 필요한 **최대 동시 세션** 수를 설정하고 생성합니다.

풀에 Agent가 한 명 이상 있어야 방문자에게 응답할 수 있습니다. 서로 다른 모델의 Agent를 함께 선택하면 방문자마다 동작이 다를 수 있다는 안내가 표시됩니다.

## 2. 사이트용 채널 만들기

채널은 설치할 사이트와 Agent 풀, 사용 한도를 연결하는 설정입니다.

1. **채널** 탭에서 **채널 생성**을 선택합니다.
2. 채널 이름을 입력하고 **에이전트 풀**에서 준비한 풀을 선택합니다.
3. **허용할 사이트**에 사이트 주소를 입력하고 **추가**를 누릅니다. 등록된 목록에 주소가 들어갔는지 확인하세요.
4. 필요하면 **고급 설정**에서 사용 한도와 세션 유지 시간을 조정합니다.
5. **채널 생성**을 선택합니다.

허용할 사이트에는 `https://example.com`처럼 **프로토콜·호스트·포트로 이루어진 주소**를 등록합니다. 개별 페이지 경로가 아니라 사이트 주소를 기준으로 연결을 허용합니다. `https://example.com`, `https://www.example.com`, `http://example.com`은 서로 다르므로 실제 위젯을 사용할 주소를 등록하세요. 별도 포트를 사용하는 사이트도 해당 포트까지 맞아야 합니다.

활성 채널에는 허용 사이트가 하나 이상 필요합니다. **연결된 풀 없음** 상태로 채널을 만들었더라도 풀을 연결하기 전에는 위젯이 응답하지 않습니다.

## 3. 설치 코드를 사이트에 추가하기

1. 채널 목록에서 대상 채널의 **설치하기**를 선택합니다.
2. **웹챗 설치 가이드**에서 **코드 복사**를 누릅니다.
3. 웹사이트의 `</body>` 태그 앞에 복사한 코드를 추가합니다. 여러 페이지에 표시하려면 해당 페이지들이 사용하는 공통 레이아웃에 추가할 수 있습니다.
4. 사이트 변경을 배포하고 페이지를 새로고침합니다.
5. 오른쪽 아래에 채팅 버튼이 나타나는지 확인합니다.

화면에서 생성한 코드를 그대로 사용하세요. 사이트 주소나 채널 토큰을 추측해서 직접 작성할 필요는 없습니다. 사이트 개발자에게 설치를 맡긴다면 복사한 코드와 적용할 사이트·페이지를 전달하세요.

## 4. 방문자 입장에서 응답 확인하기

실제로 설치한 사이트에서 채팅 버튼을 열고, Agent가 답할 수 있는 간단한 질문을 보내세요.

> 어떤 도움을 받을 수 있나요?

버튼이 보이는 것과 대화가 연결되는 것은 별개입니다. 메시지가 전송되고 Agent의 답변이 위젯에 표시되는지까지 확인하세요. 설치 위치가 여러 사이트라면 각 주소에서도 확인합니다.

## 사용 한도와 운영 설정

| 설정 위치 | 항목 | 용도 |
| --- | --- | --- |
| 풀 생성·편집 | 최대 동시 세션 | 해당 풀에서 동시에 처리할 세션 수를 제한합니다. |
| 채널의 고급 설정 | 세션당 메시지 한도, 세션 누적 출력·전체 토큰 한도 | 한 대화에서 사용할 수 있는 양을 제한합니다. |
| 채널의 고급 설정 | 일일 누적 출력·전체 토큰 한도 | 채널의 하루 사용량을 제한합니다. |
| 채널의 고급 설정 | 분당 메시지 수 | 메시지 전송 빈도를 제한합니다. |
| 채널의 고급 설정 | 세션 유지 시간 (초) | 대화 세션의 유지 시간을 설정합니다. |

출력 토큰 한도는 전체 토큰 한도보다 클 수 없습니다. 제한이나 세션 만료 안내가 나오면 화면의 안내에 따라 다시 시도하거나 새 대화를 시작하세요.

잠시 중지하려면 채널을 **편집**해 비활성화합니다. 비활성화하면 새 연결을 받지 않으며, 사이트에 넣어 둔 코드가 자동으로 삭제되는 것은 아닙니다. 버튼도 제거하려면 사이트에서 설치 코드를 제거하세요. 풀을 삭제하면 연결된 채널의 풀 연결이 해제됩니다.

## 문제가 생겼을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 풀에 원하는 Agent를 추가할 수 없음 | 조직 소속 여부와 해당 Agent에 대한 접근 권한을 확인하세요. |
| 사이트에 채팅 버튼이 보이지 않음 | 코드가 실제 배포된 페이지에 포함됐는지, 설치 코드의 스크립트가 로드되는지 확인하세요. |
| 버튼은 보이지만 연결할 수 없음 | 채널 활성 상태, 실제 사이트 주소와 허용 사이트의 일치 여부, 연결된 풀과 멤버를 확인하세요. |
| 연결되지만 응답이 없거나 이용 불가 안내가 나옴 | 풀의 Agent 실행·응답 상태와 동시 세션·사용 한도를 확인하세요. |
| 위젯을 다른 사이트로 옮김 | 채널의 허용 사이트에 새 주소를 등록하고 그 사이트에서 응답까지 확인하세요. |
