# Agent Template 안내

Agent Template 관리는 플랫폼 최고 관리자(SA)용 기능입니다. 일반 사용자용 가이드에서는 이 기능의 관리 절차를 제공하지 않습니다.

새 Agent를 만들려면 [Agent 생성하기](./create-agent.mdx)를, Agent의 지침을 설정하려면 [Agent 지침 설정](./configure-agent-workspace-files.mdx)을 참고하세요.
