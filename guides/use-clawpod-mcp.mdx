# 외부 AI 도구에서 ClawPod 사용하기

ClawPod MCP를 연결하면 외부 AI 도구에서 대화로 Agent를 조회·생성하고, 모델이나 스킬을 설정하거나 업무를 맡길 수 있습니다. 이 페이지에서는 연결 전에 살펴볼 수 있는 주요 기능과 연결 방법을 안내합니다.

연결한 AI 도구는 ClawPod가 제공하는 기능과 사용 설명을 확인할 수 있습니다. 원하는 작업을 대화로 요청하면 필요한 정보를 확인하고 진행 방법을 안내합니다. 이용 가능한 작업은 로그인한 계정의 권한과 연결한 환경에 따라 달라집니다.

## 연결하면 할 수 있는 일

| 기능 | 요청 예시 |
| --- | --- |
| Agent 목록과 상태 확인 | “내 Agent 목록과 현재 상태를 보여줘.” |
| Agent 생성 | “고객 문의를 담당할 Agent를 만들어줘. 필요한 정보는 물어봐.” |
| 모델 확인·변경 | “이 Agent의 모델을 확인하고, 비용을 줄이는 방향으로 변경하고 싶어.” |
| 스킬 조회·설치 | “이 Agent에 설치할 수 있는 스킬을 찾아보고, 내가 선택한 스킬을 설치해줘.” |
| 업무 요청 | “보고서 Agent에게 이번 주 업무 요약을 맡겨줘.” |
| 대화와 결과물 확인 | “앞에서 맡긴 작업의 답변과 결과물을 확인해줘.” |
| 조직과 구성원 확인 | “내가 접근할 수 있는 조직과 구성원을 보여줘.” |

대상이 여러 개라면 조직이나 Agent 이름을 함께 알려주세요. 생성할 Agent의 역할과 이름, 모델처럼 선택이 필요한 정보는 AI 도구의 안내에 따라 정할 수 있습니다.

## 연결 준비하기

- ClawPod 계정과 작업할 조직·Agent가 있는 ClawPod 접속 주소
- 원격 MCP와 ClawPod의 OAuth 인증 방식을 지원하는 AI 도구
- 해당 ClawPod 환경에서 MCP 연결을 사용할 수 있는 상태

AI 도구마다 지원하는 인증 방식과 설정 화면이 다를 수 있습니다. 원격 MCP를 지원하더라도 인증 방식이 호환되지 않으면 연결할 수 없습니다.

## 연결 주소 확인하기

사용하는 ClawPod 접속 주소의 도메인 뒤에 `/mcp`를 붙이세요. 채팅방 등 개별 화면의 경로는 제외합니다.

```text
https://<ClawPod 접속 도메인>/mcp
```

작업하려는 조직과 Agent가 있는 환경의 주소를 사용하세요. 여러 환경을 이용한다면 연결할 환경을 먼저 확인하세요. 가이드 사이트 주소가 아니라 실제 ClawPod 서비스의 접속 주소입니다.

### Agent에게 연결 안내를 요청한 경우

Agent는 사용자에게 주소를 묻기 전에 현재 환경에서 확인할 수 있는 ClawPod 접속 주소를 먼저 확인하세요. 접근 가능한 브라우저에 열린 ClawPod 페이지, 기존 MCP 연결 설정, 도구 응답에 포함된 ClawPod 채팅방 링크 등에서 대상 환경의 주소를 확인할 수 있습니다. 현재 사용할 수 있는 정보와 도구로 확인하고, 모든 환경에 같은 정보가 제공된다고 가정하지 마세요.

확인한 주소에서 개별 화면의 경로·쿼리·프래그먼트를 제외하고 서비스 주소의 스킴·도메인·필요한 포트를 유지한 뒤 `/mcp`를 붙입니다. 기존 MCP 설정에 대상 환경의 연결 주소가 있다면 그 주소를 확인해 사용하세요. Agent의 내부 실행 주소나 가이드 사이트 주소를 서비스 접속 주소로 대신 사용하지 마세요.

대상 환경의 주소가 확인되면 실제 주소를 채운 연결 안내를 제공하세요. 사용자가 주소를 직접 입력하지 않았다는 이유만으로 자리표시자를 남기거나 다시 물을 필요는 없습니다. 주소를 확인할 수 없거나 여러 환경 중 연결할 대상이 불명확할 때만 사용자에게 물어보세요. 주소를 확인한 것과 MCP 연결·인증이 완료된 것은 구분해서 안내하세요.

## AI 도구에 연결하기

1. 외부 AI 도구의 MCP 또는 외부 도구 연결 설정에서 원격 서버를 추가합니다. 메뉴 이름은 도구마다 다릅니다.
2. 서버 주소에 위에서 확인한 MCP 연결 주소를 입력합니다. 연결 방식 선택 항목이 있다면 **Streamable HTTP**, 인증 방식은 **OAuth**를 사용합니다.
3. 연결 과정에서 열리는 ClawPod 화면에서 로그인합니다.
4. **AI 도구 연결** 화면에서 계정과 연결 요청 정보를 확인하고 **허용**을 선택합니다.
5. 외부 AI 도구로 돌아와 다음과 같이 요청합니다.

> ClawPod에 연결됐는지 확인하고, 내가 접근할 수 있는 Agent 목록을 보여줘.

예상한 Agent가 보이지 않으면 연결한 환경과 로그인 계정이 맞는지 확인하세요. 연결 허용이 계정에 새로운 조직이나 Agent 접근 권한을 부여하는 것은 아닙니다.

## 대화로 작업하고 결과 확인하기

원하는 대상과 결과를 알려주세요. AI 도구는 필요한 ClawPod 기능을 호출하고 응답을 받아 안내합니다. 추가 정보나 사용자 조치가 필요하면 안내에 따라 진행하세요.

> 보고서 Agent에게 이번 주 업무 요약을 맡기고, 완료되면 답변과 결과물을 확인해줘.

**요청 전달과 업무 완료는 다릅니다.** Agent에게 메시지가 전달된 뒤에도 실제 작업은 진행 중일 수 있습니다. 최종 답변과 결과물을 확인하도록 요청하세요. 외부 AI 도구의 실행이 끝난 경우 같은 대화에서 진행 상황을 다시 확인할 수 있습니다.

모델을 변경하면 Agent가 재시작되므로 진행 중인 대화에 영향을 줄 수 있습니다. 모델 선택 기준은 [Agent 모델 선택하기](./select-models.mdx)를 참고하세요.

## 파일이 필요한 작업

새 파일이 필요한 요청에서는 ClawPod 채팅방에서 업로드하도록 안내받을 수 있습니다. 안내된 채팅방에 파일을 올리고 기존 요청을 이어서 진행하세요. 외부 AI 도구에 첨부한 파일이 ClawPod에도 자동으로 전달된다고 가정하지 마세요.

ClawPod 채팅의 첨부파일을 내려받으려는 경우에는 안내받은 ClawPod 채팅방 링크를 열어 다운로드합니다.

## 연결이나 작업이 안 될 때

| 상황 | 확인할 내용 |
| --- | --- |
| 연결 주소를 찾을 수 없음 | ClawPod 서비스 주소인지, 끝에 `/mcp`가 있는지, 해당 환경에서 MCP를 제공하는지 확인하세요. |
| 로그인·연결 허용을 완료할 수 없음 | AI 도구의 원격 MCP·OAuth 지원 여부와 안내된 오류를 확인하세요. |
| 예상한 조직이나 Agent가 보이지 않음 | 연결 환경, 로그인 계정과 대상 접근 권한을 확인하세요. |
| 작업에 필요한 권한이나 설정이 없음 | AI 도구가 안내하는 사용자 조치를 진행하거나 조직 관리자에게 확인하세요. |
| 요청을 보냈지만 결과가 없음 | 같은 요청을 반복해서 보내기 전에 해당 대화의 진행 상황과 Agent 상태를 확인하도록 요청하세요. |

이 연결은 ClawPod의 Agent와 작업을 다루는 기능입니다. 가이드 문서를 검색하고 읽는 기능은 [ClawPod 가이드 도구 사용하기](./use-clawpod-guide-tool.mdx)를 참고하세요.
