# Google Workspace 연결하고 사용하기

Agent에게 Google 계정 연결을 요청한 뒤 메일, 일정, 파일과 문서 작업을 맡길 수 있습니다. 실제 사용할 수 있는 작업은 연결한 계정의 접근 권한과 조직 정책에 따라 달라집니다.

## 채팅에서 시작하기

사용할 Agent와의 1:1 채팅방에서 다음처럼 요청하세요.

> 능력 레지스트리에서 `google-workspace` 스킬을 설치하고 내 Google 계정 연결을 안내해줘.

능력 레지스트리는 Agent가 사용할 스킬과 실행 도구를 찾는 공개 저장소입니다. Agent는 현재 환경에서 설치할 수 있는지 확인하고 필요한 패키지를 준비합니다. 저장소를 찾지 못하면 [공식 능력 레지스트리](https://github.com/Wondermove-Inc/clawpod-capabilities) 주소를 함께 전달하세요.

설치가 끝나도 계정 인증과 서비스 접근 확인 전에는 연결 완료가 아닙니다. 여러 계정을 연결했다면 이번 작업에 사용할 계정이나 별칭도 지정하세요.

## Google 계정 연결하기

1. Agent가 사용할 계정과 요청할 접근 권한, 인증 정보 보관·연결 해제 방법을 안내합니다. 기본 연결은 Gmail·메일 설정, Calendar, Drive, Docs, Sheets, Slides와 계정 식별 권한을 폭넓게 요청합니다. 필요한 범위를 제한하고 싶다면 연결 전에 알려주세요.
2. 안내에 따라 Agent의 브라우저에서 Google 로그인, 필요한 MFA, 계정 선택과 권한 동의를 직접 진행합니다. [Agent PC 사용](./use-agent-desktop.mdx)에서 브라우저 화면을 확인하는 방법을 참고하세요. 비밀번호·인증 코드·토큰을 채팅으로 전달하지 마세요.
3. Agent가 인증 결과를 보호된 저장소에 보관하고, 연결 계정·부여된 권한과 Gmail·Calendar·Drive 접근 결과를 확인합니다. 사용할 문서 편집 기능도 필요한 권한과 API 설정이 갖춰져 있어야 합니다.

**Google 로그인 한 번으로 모든 설정이 끝나는 것은 아닙니다.** OAuth 프로젝트 설정, 서비스 API 활성화, 회사 관리자 승인 또는 Google 검토가 필요할 수 있습니다. Agent가 안내하는 남은 설정과 사용자·관리자가 직접 해야 할 단계를 확인하세요. 심사나 관리자 승인이 대기 중이면 연결 완료로 간주하지 마세요.

각 Agent는 자신의 Google 인증 정보를 별도로 발급받습니다. 다른 Agent의 인증 파일을 복사해 연결하지 마세요. Google 로그인 정보는 이 연결 절차로 관리하며, Resend API 키처럼 채팅으로 전달해 시크릿에 등록하는 방식과는 다릅니다.

## 연결 후 요청할 수 있는 작업

| 서비스 | 요청 예시 |
| --- | --- |
| Gmail | “오늘 받은 메일 중 답장이 필요한 내용을 정리해줘.” |
| Calendar | “내일 일정을 확인하고 비어 있는 시간을 알려줘.” |
| Drive | “내가 접근할 수 있는 파일에서 이번 프로젝트 보고서를 찾아줘.” |
| Docs | “이 Google 문서를 읽고 핵심 내용을 요약해줘.” |
| Sheets | “이 스프레드시트의 지정한 범위를 읽고 합계를 정리해줘.” |
| Slides | “이 프레젠테이션의 슬라이드별 핵심 내용을 정리해줘.” |

메일 발송, 일정 생성·수정, 파일 공유, 문서·시트·슬라이드 내용 편집도 요청할 수 있습니다. 대상 계정, 파일 링크, 수신자·공유 대상과 원하는 변경을 구체적으로 알려주세요. 계정 연결 자체가 모든 발송·공유·삭제를 요청한 것은 아닙니다.

> 이 Google 문서 마지막에 회의 요약을 추가해줘. 공유 권한은 변경하지 마.

## 연결이 안 되거나 해제하고 싶을 때

- **로그인됐지만 작업이 실패함:** 사용할 계정, 해당 파일 접근 권한, 서비스 API 활성화 여부와 회사 정책을 확인하도록 요청하세요.
- **권한 부족:** 필요한 권한으로 다시 연결하도록 요청하세요. 문서 편집 기능이 추가되기 전에 연결한 계정은 Docs·Sheets·Slides용 추가 동의가 필요할 수 있습니다.
- **연결 만료 또는 취소:** 해당 Agent에서 재연결을 요청하세요. 임시 테스트 상태의 OAuth 앱은 장기 사용을 위한 추가 설정이 필요할 수 있습니다.
- **연결 해제:** Agent에게 대상 계정을 지정해 로그아웃·저장된 인증 정보 삭제를 요청하고, Google 계정의 연결된 앱에서도 접근 권한을 취소하세요. 스킬 삭제와 Google 권한 취소는 별개입니다.

인증 정보 취급의 공통 원칙은 [시크릿 다루기](./handle-secrets.mdx)를 참고하세요.
