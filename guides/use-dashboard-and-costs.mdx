# 대시보드와 비용 확인

대시보드와 비용 메뉴는 역할·권한에 따라 보입니다. 상단 **관리자**에서 시작하세요.

## 대시보드

1. 사이드바 **대시보드**를 엽니다.
2. 상단 기간 선택에서 조회할 범위를 고릅니다.
3. **빠른 인사이트**, **상위 에이전트**, **최근 활동**, **워크스페이스 사용량**을 확인합니다.
4. Agent 상태를 더 확인하려면 해당 Agent 링크 또는 **관리 → 에이전트**를 엽니다.

워크스페이스 사용량은 테넌트의 플랜과 멤버·조직·Agent 수 및 한도를 표시합니다. 별도 설정 메뉴로 이동할 필요가 없습니다.

## LLM 사용 비용

**분석 → LLM 사용 비용**에서 기간별 총 비용과 모델·조직·Agent별 비용을 확인합니다. 상세 절차는 [분석 요약과 비용](./use-analytics.mdx)을 참고하세요.

이 화면의 LLM 비용 분석과 [요금제 관리의 구독 결제 내역](./manage-billing.mdx)은 별개입니다. 지표를 비교할 때 기간과 범위를 맞추세요.
