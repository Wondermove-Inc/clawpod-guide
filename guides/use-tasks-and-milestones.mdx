# Tasks와 Milestone으로 작업 추적

Tasks는 조직 단위의 작업 현황을 보고 추적하는 기능입니다. Portal은 Kanban과 목록 보기, Task 상세, 조직별 통계, Milestone, CSV export를 제공합니다.

## 조직 Task board 열기

1. Portal에서 **<!-- ui-label: nav.tasks -->태스크<!-- /ui-label -->**를 엽니다.
2. 작업할 조직을 선택합니다.
3. Kanban 또는 목록 보기에서 Task를 검색·필터링합니다.
4. Task를 열어 상태, 담당자, 보고자, 마감일, 활동 기록, 댓글, 첨부, 연결된 자료를 확인합니다.

Task가 어떤 Agent 또는 자동화에서 생성됐는지는 활동 기록과 연결된 Room·event를 함께 확인하세요. 제목만 보고 원인이나 소유자를 추정하지 않는 편이 안전합니다.

## 상태 변경과 진행 확인

Kanban에서 Task를 이동하거나 상세 화면에서 상태를 바꾸면 해당 조직의 작업 현황에 반영됩니다. 상태를 Done으로 바꾸기 전에는 완료 기준, 산출물, 관련 Agent의 최종 결과를 확인하세요.

동시에 여러 사용자가 상태를 바꿀 수 있으므로, 중요한 전환에는 comment나 활동 기록으로 근거를 남기는 것이 좋습니다.

## 댓글과 첨부

Task 상세의 **댓글**에 결정 근거, 담당자에게 전달할 내용, 차단 사유를 남길 수 있습니다. 댓글 작성자는 자신의 댓글을 수정하거나 삭제할 수 있습니다. 댓글 내용은 Markdown으로 표시되며, Task 댓글이 추가되면 관련 알림이 생성될 수 있습니다.

**첨부** 영역에는 파일을 끌어 놓거나 선택해 올립니다. Task와 Milestone 첨부는 파일당 50 MB이며, 허용 형식은 [파일 형식과 artifact](/guides/file-formats-and-artifacts)를 따릅니다. 업로드한 파일은 목록에서 내려받거나 삭제할 수 있습니다. 삭제 전에 다른 Task 댓글이나 외부 작업에서 이 파일을 참조하지 않는지 확인하세요.

## GitHub 이슈와 Pull Request 연결

Task 상세의 **GitHub** 영역에서 **연결**을 선택하고 다음을 입력합니다.

1. 저장소 소유자
2. 저장소 이름
3. 이슈 또는 Pull Request 번호
4. 연결 종류: Issue 또는 Pull Request

연결 뒤에는 저장소·번호·종류·연결 시 저장한 상태가 Task에 표시되며, 링크를 열거나 연결을 해제할 수 있습니다. 이 기능은 GitHub 이슈나 Pull Request를 생성·수정·병합하거나 live 상태를 동기화하지 않고 Task에 참조를 연결하는 기능입니다.

## Milestone 만들기

1. 조직 Task board에서 **<!-- ui-label: tasks.milestones.create -->마일스톤 생성<!-- /ui-label -->**을 선택합니다.
2. 이름, 설명, 시작일, 마감일, 보고자, 필요한 첨부를 입력합니다.
3. Milestone을 만든 뒤 각 Task 상세에서 이 Milestone을 선택해 연결합니다.
4. 진행률과 Done 수를 확인합니다.

Milestone에서 Task를 제거해도 Task 자체가 삭제되는 것은 아닙니다. 릴리스나 고객 약속과 연결된 Milestone을 삭제·변경하기 전에는 담당자와 영향을 확인하세요.

## CSV export

1. 조직 Task board에서 필요한 검색·상태·담당자·Milestone 필터를 적용합니다.
2. 결과가 있는지 확인한 뒤 toolbar의 **<!-- ui-label: tasks.export.csv -->CSV 내보내기<!-- /ui-label -->**를 선택합니다.
3. 내려받은 파일의 조직·기간·행 수가 의도한 범위인지 확인합니다.

Audit Log와 마찬가지로 export 파일은 조직 운영 데이터이므로 승인된 저장소에 보관하고 공유 범위를 제한하세요.

## 기능 범위 주의

Task에서 Agent에게 지시를 전달하는 내부 relay와 자동 escalation은 일반 작업 보드 조작 기능이 아닙니다. Portal에서 확인 가능한 Task·Milestone·댓글·첨부·GitHub 참조 흐름과 자동 실행을 같은 보장으로 취급하지 마세요.
