# Slack에서 Agent와 대화하기

ClawPod Agent를 Slack 워크스페이스의 채널에 연결하면 Slack에서 봇을 멘션해 업무를 요청할 수 있습니다. 별도 스킬 설치 요청 없이 Agent에게 Slack 연결을 요청하는 흐름입니다. Agent가 현재 환경의 Slack 연결 기능과 브라우저 사용 가능 상태부터 확인하도록 하세요.

## 준비하기

- 연결할 ClawPod Agent와 [Agent 브라우저를 사용할 수 있는 환경](./use-agent-desktop.mdx)
- Slack 계정과 대상 워크스페이스에 앱을 설치할 권한

조직에서 앱 설치를 제한한다면 Slack 관리자 승인이 필요할 수 있습니다. Agent 전용 브라우저에서 로그인하고, 개인 브라우저 프로필이나 비밀번호 관리자를 공유하지 마세요.

## Agent에게 연결 요청하기

ClawPod에서 대상 Agent와의 1:1 채팅방을 열고, 다음처럼 짧게 요청하세요.

> Slack에 너를 연결하고 싶어. Socket Mode 방식으로 연결해주고, 네 내부 브라우저에 Slack 로그인 화면을 열어줘. 로그인은 내가 할게. 필요한 정보는 나에게 물어봐줘.

워크스페이스·채널·봇 이름을 처음부터 모두 정할 필요는 없습니다. Agent의 질문에 답하면서 연결할 대상을 정하세요. 예를 들어 “회사 워크스페이스의 기존 프로젝트 채널에 연결하고 싶어”라고 답할 수 있습니다. 채널이 없다면 새로 만들지와 공개·비공개 여부를 함께 정하세요.

앱과 토큰 등 기술 설정은 Agent의 안내를 따라 진행하면 됩니다. 토큰 값을 직접 채팅에 붙여 넣을 필요는 없습니다. 실제 질문 순서는 현재 로그인·연결 상태에 따라 달라질 수 있습니다.

## 로그인하고 연결 설정하기

1. Agent가 연 Slack 로그인 화면에서 로그인·MFA 등 본인 인증을 직접 완료합니다. [Agent PC 사용](./use-agent-desktop.mdx)을 참고하세요.
2. 대상 워크스페이스와 봇 이름을 확인합니다. Agent가 Slack 앱을 준비하고 Socket Mode 연결에 필요한 설정을 진행합니다.
3. 앱 설치 시 요청되는 권한을 확인하고 필요한 승인을 진행합니다. 관리자 승인 요청이 표시되면 승인이 끝날 때까지 해당 단계는 대기 상태입니다.
4. Agent가 Bot Token과 App-Level Token을 보호된 방식으로 보관하고 Slack 연결 설정에 적용합니다. 토큰 저장만으로 연결 완료라고 판단하지 말고, 실제 연결 상태까지 확인하도록 요청하세요.
5. 대상 채널에 봇이 참여하고 해당 채널 ID가 Agent의 연결 허용 목록에 등록됐는지 확인합니다. 비공개 채널은 접근 권한이 있는 기존 멤버의 초대가 필요할 수 있습니다.

직접 봇을 초대해야 한다면 Slack에서 대상 채널을 열고 `/invite`를 입력해 봇을 선택하세요. 채널이 없다면 생성할 채널의 공개·비공개 여부를 먼저 정하세요.

토큰 값은 채팅·일반 문서·보고서에 복사하지 마세요. 인증 정보 취급은 [시크릿 다루기](./handle-secrets.mdx)를 참고하세요. 시크릿에 값을 등록하는 것과 Slack 연결에서 사용할 수 있도록 설정하는 것은 별개입니다.

## 멘션으로 대화 시작하기

연결한 Slack 채널에서 `@봇이름`을 멘션해 대화를 시작하세요. Slack의 자동완성 목록에서 봇을 선택한 뒤 메시지를 보냅니다.

> @봇이름 연결 확인해줘.

이름을 일반 텍스트로 적는 것과 실제 봇 멘션은 다릅니다. 선택한 봇이 Slack의 멘션으로 표시되는지 확인하세요.

설정이 끝나면 Agent에게 “연결한 채널에 시험 메시지를 보내줘”라고 요청하고, Slack에서 봇을 멘션해 보세요.

연결 완료는 다음 두 가지로 확인합니다.

- **Agent → Slack:** 요청한 시험 메시지가 대상 채널에 표시됩니다.
- **Slack → Agent:** 사용자가 보낸 멘션에 Agent가 해당 채널 또는 스레드에서 응답합니다.

앱 설치나 토큰 발급만 끝난 상태는 양방향 대화가 확인된 상태와 다릅니다. Agent에게 완료된 단계, 테스트 결과와 남은 작업을 정리하도록 요청하세요.

## 연결이 안 되거나 해제하고 싶을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 설치 시 관리자 승인 요청 | 앱 이름과 요청 권한을 확인하고 조직의 승인 절차를 따르세요. 앱 생성 권한과 설치 권한은 다를 수 있습니다. |
| `channel_not_found` | 채널 존재 여부, 봇의 채널 참여와 접근 권한, 정확한 채널 ID를 확인하도록 요청하세요. |
| 시험 메시지는 보이지만 멘션에 응답하지 않음 | 실제 봇 멘션인지 확인하고, Agent에게 채널 허용 목록·수신 설정·연결 상태와 설정 적용 여부를 점검하도록 요청하세요. |
| Slack 연결 자체가 실패함 | Agent에게 Socket Mode와 두 토큰의 사용 가능 상태를 확인하도록 요청하세요. 오류 보고에 토큰 값을 포함하지 마세요. |

연결을 중지하려면 Agent에게 대상 워크스페이스·채널을 지정해 연결 중지를 요청하세요. Slack 앱을 완전히 제거하거나 토큰을 폐기하려면 Slack에서도 해당 작업을 진행해야 합니다. 다른 연결에서 같은 앱을 사용하는지 먼저 확인하세요.
