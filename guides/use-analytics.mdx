# 분석 요약과 LLM 사용 비용 확인

## 분석 화면 열기

상단 **관리자**를 선택한 뒤 사이드바 **분석**에서 다음 메뉴를 엽니다. 메뉴와 데이터 범위는 내 역할과 권한에 따라 달라집니다.

| 메뉴 | 확인할 내용 |
| --- | --- |
| 분석 요약 | 활성 Agent, 처리된 메시지, 총 비용·토큰, LLM 호출, 대화 및 조직별 지표 |
| LLM 사용 비용 | 총 비용, 모델·조직·Agent별 비용, 일별 지출 등 |

각 화면의 기간 선택에서 원하는 범위를 고릅니다. 서로 비교할 때는 같은 기간과 조직 범위인지 확인하세요. LLM 사용 비용은 구독 결제 내역과 별도이며, 구독은 [요금제 관리](./manage-billing.mdx)에서 확인합니다.

## 운영 점검

1. 분석 요약에서 활동량과 오류율을 확인합니다.
2. 비용 화면에서 사용량·모델·Agent별 변화와 비용 증가가 일치하는지 봅니다.
3. 원인이 불명확하면 대상 Agent의 상세 정보와 로그, 관련 웹훅 이벤트를 확인합니다.

지표만으로 장애 원인을 확정하거나 설정을 자동 변경하지 마세요. 일반 고객 안내에는 플랫폼 운영용 Monitoring·System 메뉴를 포함하지 않습니다.
