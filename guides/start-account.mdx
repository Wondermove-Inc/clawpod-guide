# 가입, 로그인, 계정 복구

직접 회원가입한 ClawPod Portal 계정은 이메일 인증을 마친 뒤 로그인합니다. 조직 초대를 통한 가입은 초대 수락 흐름에서 계정과 멤버십이 활성화될 수 있으므로, 받은 초대 링크에서 시작하는 편이 정확합니다.

## 회원가입

1. Portal의 **<!-- ui-label: register.signUp -->회원가입<!-- /ui-label -->**에서 이름, 이메일 주소, 비밀번호를 입력합니다.
2. 사용 목적을 고르고, 직접 가입이면 workspace 이름도 입력합니다. 조직 초대 링크로 들어온 경우에는 초대의 이메일과 조직 정보가 이미 연결됩니다.
3. 이용약관과 개인정보 처리방침에 동의합니다. 화면에 B2B 약관 동의가 표시되면 함께 동의해야 합니다.
4. 계속을 선택하고 받은 이메일의 6자리 인증 코드를 입력합니다. 코드를 붙여넣어도 됩니다.
5. 코드가 만료되었거나 받지 못했다면 **<!-- ui-label: verify.resendCode -->인증 코드 다시 보내기<!-- /ui-label -->**를 선택합니다. 재전송 버튼은 60초 간격으로 사용할 수 있습니다.

비밀번호는 8자 이상이며 대문자, 소문자, 숫자, 특수문자를 각각 하나 이상 포함해야 합니다. 인증이 완료되면 Portal로 이동합니다. 현재 직접 가입은 이메일 인증 뒤 관리자 승인 대기 화면으로 이동할 수 있습니다. 초대 가입은 조직 초대의 조건에 따라 진행됩니다.

새 workspace의 온보딩 화면이 열리면 회사 정보와 provider 연결을 마쳐 초기 Agent를 준비합니다. 자세한 흐름은 [새 workspace 온보딩 완료하기](/guides/complete-onboarding)를 보세요.

초대받은 조직에 참여하려면 별도 계정을 먼저 만들지 말고 받은 초대 링크를 사용하세요. 자세한 절차는 [조직 초대 수락하기](/guides/accept-organization-invite)를 보세요.

## 로그인

1. **<!-- ui-label: login.signIn -->로그인<!-- /ui-label -->**에서 이메일과 비밀번호를 입력합니다.
2. 개인 기기에서만 필요하면 **<!-- ui-label: login.rememberMe -->로그인 상태 유지<!-- /ui-label -->**를 선택합니다. 공용 기기에서는 선택하지 마세요.
3. 이메일 인증이 끝나지 않은 계정은 인증 코드 화면으로 이동합니다. 이메일 인증을 마친 뒤 다시 로그인합니다.

로그인을 여러 번 실패하면 잠시 시도가 제한될 수 있습니다. 이때 비밀번호를 반복해서 입력하지 말고 비밀번호 재설정을 사용하세요.

## MFA로 로그인하기

Profile에서 MFA를 켠 계정은 비밀번호 뒤에 인증기 앱의 6자리 코드를 입력해야 합니다.

1. 로그인 화면에서 이메일과 비밀번호를 제출합니다.
2. MFA 화면에서 인증기 앱의 현재 6자리 코드를 입력합니다.
3. 인증기를 사용할 수 없으면 **<!-- ui-label: auth.mfa.useRecoveryCode -->복구 코드 사용<!-- /ui-label -->**을 선택하고 보관해 둔 recovery code를 입력합니다.

MFA 설정은 [계정 보안과 MFA 관리](/guides/secure-your-account)를 따르세요. recovery code는 다시 표시되지 않을 수 있으므로 생성 직후 조직의 비밀값 보관 절차에 따라 보관하고, Chat이나 문서에 붙여 넣지 마세요.

## 비밀번호 재설정

1. 로그인 화면에서 **<!-- ui-label: login.forgotPassword -->비밀번호를 잊으셨나요?<!-- /ui-label -->**를 선택합니다.
2. 계정 이메일을 입력하고 전송을 선택합니다.
3. 받은 이메일의 6자리 코드를 입력한 뒤, 새 비밀번호와 확인 값을 입력합니다.
4. 완료되면 로그인 화면으로 돌아가 새 비밀번호로 로그인합니다.

보안을 위해 요청한 이메일이 실제 계정인지와 관계없이 동일한 다음 단계가 표시될 수 있습니다. 메일이 오지 않으면 주소를 다시 확인하고, 조직의 메일 필터도 확인하세요.

## 현재 제공하지 않는 계정 화면

현재 Portal에는 기기별 로그인 세션 목록이나 원격 로그아웃 화면이 없습니다. 계정 접근이 의심되면 즉시 비밀번호를 변경하고 MFA를 정비한 뒤, 조직 관리자에게 접근 회수와 Audit Log 확인을 요청하세요.

<Note>
가입·로그인 문제를 지원에 전달할 때 비밀번호, MFA 코드, recovery code, browser cookie를 보내지 마세요. 이메일 주소와 발생 시각, 화면의 오류 문구만 공유하면 됩니다.
</Note>
