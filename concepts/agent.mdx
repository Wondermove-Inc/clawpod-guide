# Agent란 무엇인가요?

Agent는 특정 업무를 돕도록 설정한 AI 작업 단위입니다. 예를 들어 회의 내용을 정리하거나, 고객 문의 초안을 만들거나, 팀의 반복 업무를 지원하도록 만들 수 있습니다.

하나의 Agent는 다음 설정을 함께 사용합니다.

| 구성 | 의미 |
| --- | --- |
| 역할과 기본 지침 | Agent가 어떤 일을 하고 어떤 기준을 따라야 하는지 정합니다. |
| Model | Agent가 응답을 생성할 때 사용하는 AI model입니다. |
| Credential | 선택한 model 또는 연동 서비스에 안전하게 접근하기 위한 조직의 연결 정보입니다. |
| Skill과 도구 | Agent가 허용된 범위에서 수행할 수 있는 추가 작업입니다. 일부 기능은 설치·연결·권한 부여가 필요합니다. |

Agent의 권한은 만든 사람의 개인 권한이 아니라 조직이 부여한 정책과 연결 설정의 범위 안에서 동작합니다. 중요한 작업을 맡길 때는 역할, 지침, 접근 권한을 함께 검토하세요.

## 좋은 Agent 지침의 예

좋은 지침은 목표와 경계를 함께 설명합니다.

> 고객 문의를 친절한 한국어로 요약하고 답변 초안을 작성하세요. 확정되지 않은 정책은 단정하지 말고 담당자 확인이 필요하다고 알려 주세요.

Agent가 할 수 없는 일, 검토가 필요한 일, 다루면 안 되는 정보도 함께 적으면 결과가 더 일관됩니다.

사용 가능한 기능과 활성화 조건은 [Agent 기능](/capabilities/index)에서 확인하세요.
