# ClawPod 시작하기

ClawPod는 팀이 목적에 맞는 AI Agent를 만들고, 대화와 작업을 함께 관리할 수 있는 제품입니다.

처음 사용하는 경우 아래 순서로 시작하세요.

1. [계정을 만들고 로그인](/guides/start-account)하거나 조직 초대를 수락합니다.
2. 사용할 AI credential을 연결합니다. 이 작업은 조직의 권한 정책에 따라 관리자만 할 수 있습니다.
3. [첫 Agent 만들기](/start/first-agent)를 완료합니다.
4. Agent와 대화를 시작하고, 필요한 업무 지침을 보완합니다.

## 내게 맞는 시작 경로

| 목적 | 먼저 읽을 문서 |
| --- | --- |
| 계정을 만들거나 로그인 문제를 해결하기 | [가입, 로그인, 계정 복구](/guides/start-account) |
| 팀을 위해 첫 Agent를 만들기 | [첫 Agent 만들기](/start/first-agent) |
| Agent가 무엇이고 어떻게 동작하는지 이해하기 | [Agent란 무엇인가요?](/concepts/agent) |
| 오류나 접근 문제 해결하기 | [도움말](/help/index) |

제품 화면의 메뉴나 선택지는 내 역할과 조직 설정에 따라 달라질 수 있습니다.
