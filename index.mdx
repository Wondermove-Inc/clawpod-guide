# ClawPod 시작하기

ClawPod는 팀의 목적에 맞는 AI Agent를 만들고, 대화·파일·작업을 함께 관리하는 제품입니다. Agent에게 맡길 업무를 정하고 필요한 AI 연결과 지침을 준비해 시작하세요.

## 처음 사용하는 순서

1. [계정을 만들고 로그인](./guides/start-account.mdx)하거나 [조직 초대를 수락](./guides/accept-organization-invite.mdx)합니다.
2. 새 workspace를 만드는 경우 [온보딩](./guides/complete-onboarding.mdx)을 완료합니다.
3. [AI 키 관리](./guides/manage-credentials.mdx)에서 사용할 AI 연결을 준비합니다. 연결 권한이 없으면 조직 관리자에게 요청하세요.
4. [첫 Agent](./start/first-agent.mdx)를 만들고 역할과 기본 지침을 검토합니다.
5. [Chat Room](./guides/use-chat-room.mdx)에서 작은 업무를 요청하고 결과를 확인합니다.

## 무엇을 하고 싶으신가요?

| 원하는 결과 | 시작할 가이드 |
| --- | --- |
| 문서를 읽고 요약이나 파일 받기 | [파일 형식과 결과물](./guides/file-formats-and-artifacts.mdx) |
| 웹 페이지 확인과 브라우저 작업 맡기기 | [Browser와 CLI 작업 요청](./guides/use-browser-and-cli.mdx) |
| 팀의 업무와 진행 상태 관리하기 | [Tasks와 Milestone](./guides/use-tasks-and-milestones.mdx) |
| 회의 내용을 전사하고 요약하기 | [회의록](./guides/use-meeting-minutes.mdx) |
| Agent의 역할과 응답 방식 조정하기 | [Agent 지침 설정](./guides/configure-agent-workspace-files.mdx) |
| 외부 이벤트를 Agent에게 전달하기 | [Webhook](./guides/send-webhook-to-agent.mdx) |
| 조직의 멤버·권한·비용 관리하기 | [조직 관리](./guides/manage-organization.mdx), [구독 관리](./guides/manage-billing.mdx) |

메뉴와 작업 가능 범위는 내 권한, 조직 설정, 요금제와 Agent의 준비 상태에 따라 달라집니다. [기능 안내](./capabilities/catalog.mdx)에서 필요한 조건을 확인하고, 접근이나 실행에 문제가 있으면 [도움말](./help/index.mdx)을 참고하세요.
