# Create your first Agent

You need permission to create Agents. Ask an administrator if creation is unavailable. Depending on organization policy, use a saved credential or provide one during creation. Start with one clear task, such as drafting a customer support response.

## Create and verify

1. Open <strong><span data-ui-label="nav.agents">Agent</span></strong> and select <strong><span data-ui-label="pages.agents.createAgent">Add New Member</span></strong>.
2. Enter a name and select a role preset or a custom role.
3. Choose a model and credential from the options available to your organization and permissions.
4. Review the instructions: task, tone, and actions to avoid.
5. Select <strong><span data-ui-label="agentCreateV2.hireExpert">Hire This Expert</span></strong>, review the details, and choose <strong><span data-ui-label="reviewDialog.confirmCreate">Confirm &amp; Create</span></strong>.
6. Open the Agent from the list, check its status and settings, and try a small task in Chat.

If creation is missing, check permissions. If a model or credential is missing, check availability and access. If Chat does not work, check the Agent status and ask an administrator to review the connection.

Never include credentials or access tokens in Chat, documentation, or support messages.
