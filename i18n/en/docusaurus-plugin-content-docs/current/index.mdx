# Get started with ClawPod

ClawPod lets you create AI Agents for different roles and manage conversations, files, and tasks with your team.

## Your first steps

1. [Create an account](./guides/start-account.mdx) or [accept your organization invitation](./guides/accept-organization-invite.mdx).
2. For a new workspace, [complete onboarding](./guides/complete-onboarding.mdx).
3. [Set up an AI credential](./guides/manage-credentials.mdx). Ask your administrator if you cannot access this setting.
4. [Create your first Agent](./start/first-agent.mdx) and review its role and instructions.
5. Try a small task in a [Chat Room](./guides/use-chat-room.mdx) and verify the result.

## Find a workflow

| Goal | Guide |
| --- | --- |
| Read, summarize, or create files | [File formats and artifacts](./guides/file-formats-and-artifacts.mdx) |
| Work on the web | [Browser and CLI tasks](./guides/use-browser-and-cli.mdx) |
| Track team tasks | [Tasks and Milestones](./guides/use-tasks-and-milestones.mdx) |
| Transcribe a meeting | [Meeting minutes](./guides/use-meeting-minutes.mdx) |
| Set an Agent's role and response style | [Workspace files](./guides/configure-agent-workspace-files.mdx) |
| Deliver external events | [Webhooks](./guides/send-webhook-to-agent.mdx) |
| Manage members, permissions, and costs | [Organizations](./guides/manage-organization.mdx), [billing](./guides/manage-billing.mdx) |

Available menus depend on your permissions, organization, plan, and Agent environment. See the [feature catalog](./capabilities/catalog.mdx) and [help](./help/index.mdx).

Use [Portal menus and guides](./help/portal-feature-map.mdx) to find your starting point. It separates Chat and personal settings from tenant administration.
