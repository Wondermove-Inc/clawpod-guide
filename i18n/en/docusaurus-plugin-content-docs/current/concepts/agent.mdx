# What is an Agent?

An Agent is a configured unit of work: for example, meeting summaries, customer response drafts, or recurring tasks.

| Setting | Purpose |
| --- | --- |
| Role and instructions | Define the task and response style |
| Model | Supplies the AI model used for the task |
| Organization credential | Connects the Agent to an authorized provider |
| Skills and tools | Add capabilities that may require installation, connections, and permissions |

An Agent follows its own policies and connections; it does not automatically inherit every personal permission of its creator. Review important outputs and actions.

For example: “Summarize customer requests in friendly Korean and draft a response. Do not assert unconfirmed policies; identify anything that needs confirmation from its owner.”

Include what the Agent must not do, when a person should review its work, and information it must not use or reveal. See the [feature catalog](../capabilities/catalog.mdx).
