# ClawPod feature catalog

Use this catalog to choose a workflow. Availability depends on your organization, permissions, plan, and Agent environment.

## Portal workflows

| Goal | Requirements and guide |
| --- | --- |
| Create or manage Agents | Creation permissions and quota: [create](../guides/create-agent.mdx), [manage](../guides/manage-agent.mdx) |
| Chat and exchange files | Organization and Room access: [Chat Rooms](../guides/use-chat-room.mdx), [file formats](../guides/file-formats-and-artifacts.mdx) |
| Read past conversations | Accessible Rooms: [Previous conversations](../guides/use-chat-archive.mdx) |
| Track team work | Organization access: [Tasks and Milestones](../guides/use-tasks-and-milestones.mdx) |
| Create meeting minutes | Meeting access, participant consent, and organization policy: [meetings](../guides/use-meeting-minutes.mdx) |
| Configure AI keys and models | Credential and Agent management permissions: [credentials](../guides/manage-credentials.mdx), [models](../guides/select-models.mdx) |
| Install Skills | Skill permissions and a target Agent: [Skills](../guides/manage-skills.mdx) |
| Configure Agent instructions | [Workspace files](../guides/configure-agent-workspace-files.mdx) |
| Deliver events | Webhook permissions, source, and target: [webhooks](../guides/send-webhook-to-agent.mdx) |
| Manage members and access | Organization and IAM permissions: [organizations](../guides/manage-organization.mdx), [IAM](../guides/manage-iam.mdx) |
| Review analytics and billing | Appropriate access: [analytics](../guides/use-analytics.mdx), [billing](../guides/manage-billing.mdx) |
| Manage account security and records | [MFA](../guides/secure-your-account.mdx), [notifications](../guides/manage-notifications.mdx), [audit log](../guides/use-audit-log.mdx) |

## Agent tasks

| Task | Check first |
| --- | --- |
| Files and coding | Allowed paths and available tools: [CLI work](../guides/use-browser-and-cli.mdx) |
| Browser work | Browser readiness and site access: [browser and web](./browser-and-web.mdx) |
| Remote desktop | A running, supported Agent: [Agent Desktop](../guides/use-agent-desktop.mdx) |
| Memory and instructions | Retention policy and scope: [memory](./memory-and-configuration.mdx) |
| Image generation and audio transcription | OpenAI tools, input rights, and budget: [media](./channels-and-media.mdx) |

Specify the target, expected result, allowed changes, and external transfers. State what is unknown instead of assuming readiness. See [availability checks](./consumer-availability.mdx).
