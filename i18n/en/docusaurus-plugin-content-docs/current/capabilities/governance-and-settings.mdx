# Account and organization administration

Administration features depend on your role, organization access, plan, and limits. If a menu is missing, first verify the account and organization.

| Area | Workflow | Guide |
| --- | --- | --- |
| Organizations and members | Create organizations and connect users/Agents | [Organizations](../guides/manage-organization.mdx) |
| Access | Attach Policies and inspect effective permissions | [IAM](../guides/manage-iam.mdx) |
| Security | Passwords and MFA | [Account security](../guides/secure-your-account.mdx) |
| Notifications | Types and delivery preferences | [Notifications](../guides/manage-notifications.mdx) |
| Audit | Read and export permitted change records | [Audit Log](../guides/use-audit-log.mdx) |
| Activity and cost | Accessible Agent activity, conversations, and costs | [Analytics](../guides/use-analytics.mdx), [Dashboard and Costs](../guides/use-dashboard-and-costs.mdx) |
| Subscriptions and limits | Status, changes, cancellation, and usage | [Billing](../guides/manage-billing.mdx), [Workspace usage](../guides/check-workspace-and-system.mdx) |

Before changing settings, verify the organization and target users/Agents and grant only necessary access. Member removal, disconnection, and subscription changes can affect existing work; follow each guide's conditions and verification.

For errors, check the target, limits, and error message before broadening permissions. Platform-wide settings and operational recovery are outside this public organization-user guide.
