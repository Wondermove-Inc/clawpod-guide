# Skills and tools

Bundled tools vary by runtime. Lightweight Agents may lack GUI and some office or media tools. Verify availability before assigning work, including browser tasks.

Specify allowed files, commands, browser activity, and external transfers. For example: “Read only this week's CSV files in `/workspace/reports`, write `weekly-summary.md`, and do not send data externally.”

Connect credentials through settings, not packages or Chat. Available tools do not override policy restrictions.

## Add skills from the library

Follow [skill installation and management](../guides/manage-skills.mdx) to find official or private skills and install or remove them on Agents. Check installation status separately from actual tool and service readiness.
