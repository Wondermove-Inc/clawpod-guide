# Find previous conversations

## Find a Room

1. Select **Chat** at the top.
2. Enter the Room name in the sidebar's room search.
3. If the recent list does not include it and **View all** is shown, expand the list.
4. Select an accessible Room to read its history.

This workflow does not require a separate Chat Archive menu. Do not guess addresses or IDs for Rooms you cannot see.

## Find a message

Open **Message search** and enter a term. Search applies to loaded messages, so scroll up to load older history first. See the [Chat Room guide](./use-chat-room.mdx).

Opening a Room may update its read status. You do not need to delete a Room or change its participants to read history.
