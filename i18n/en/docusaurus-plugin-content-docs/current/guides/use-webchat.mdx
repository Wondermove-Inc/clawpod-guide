# Install a WebChat widget on your website

WebChat adds a chat button to your website so visitors can talk to a ClawPod Agent. Use **WebChat** in the Portal to configure the responding Agents and allowed sites, then add the generated installation code to your site.

## Before you start

- Permission to access WebChat and manage pools and channels
- An Agent to respond to visitors
- Your website address and permission to edit and deploy its code

WebChat is available in the Admin sidebar, subject to your role, permissions, and menu visibility settings. Contact your tenant administrator if the menu or required creation buttons are missing.

**Agents assigned to an organization cannot be added to a WebChat pool.** Prepare an Agent without an organization assignment and review the information and materials it should use when responding to visitors. See [creating an Agent](./create-agent.mdx).

## 1. Create an Agent pool

A pool groups the Agents that respond to WebChat visitors.

1. Open **Admin → WebChat** in the Portal.
2. On the **Pools** tab, select **Create pool**.
3. Enter a name and select the responding Agents under **Members**.
4. Set **Max concurrent sessions** as needed and create the pool.

A pool needs at least one Agent to respond to visitors. Selecting Agents with different models displays a warning that behavior may vary between visitors.

## 2. Create a channel for your site

A channel connects your allowed sites, Agent pool, and usage limits.

1. On the **Channels** tab, select **Create channel**.
2. Enter a channel name and choose the prepared **Agent pool**.
3. Enter a website address under **Allowed sites** and select **Add**. Check that it appears in the registered list.
4. Adjust usage limits and session duration in **Advanced settings** if needed.
5. Select **Create channel**.

Register an address consisting of the **protocol, host, and port**, such as `https://example.com`. Access is allowed by site origin, rather than individual page path. `https://example.com`, `https://www.example.com`, and `http://example.com` are different addresses; register the one your visitors actually use. Sites using a separate port must match that port too.

An active channel requires at least one allowed site. Creating a channel without a connected pool does not make the widget ready to respond; connect a pool first.

## 3. Add the installation code to your site

1. Select **Install** for the target channel in the channel list.
2. Select **Copy code** in the installation guide.
3. Paste the code before your website's `</body>` tag. To show the widget on multiple pages, you can add it to their shared layout.
4. Deploy the website change and refresh the page.
5. Check that the chat button appears in the bottom-right corner.

Use the code generated by the Portal as provided. You do not need to guess the widget host or channel token. If a website developer handles installation, give them the copied code and the sites or pages where it should appear.

## 4. Verify a visitor conversation

Open the chat button on the actual website and send a simple question the Agent can answer.

> What can you help me with?

A visible button does not prove the conversation is connected. Check that your message is sent and the Agent's reply appears in the widget. If you install on multiple sites, verify each address.

## Usage limits and operation

| Location | Setting | Purpose |
| --- | --- | --- |
| Pool creation or editing | Max concurrent sessions | Limit how many sessions the pool handles at once. |
| Channel advanced settings | Messages per session and session output/total token limits | Limit usage within one conversation. |
| Channel advanced settings | Daily output/total token limits | Limit the channel's daily usage. |
| Channel advanced settings | Messages per minute | Limit message frequency. |
| Channel advanced settings | Session duration (seconds) | Set how long a conversation session is maintained. |

An output token limit cannot exceed the total token limit. If the widget shows a limit or session-expiration message, follow its instructions to retry or start a new conversation.

To pause service, **Edit** the channel and deactivate it. This stops new connections but does not remove the code from your website. Remove the installation code from the site if you also want to remove the button. Deleting a pool unbinds it from connected channels.

## Troubleshooting

| Situation | What to check |
| --- | --- |
| Cannot add an Agent to a pool | Check organization assignment and your access to the Agent. |
| No chat button appears | Check that the deployed page includes the installation code and that its script loads. |
| The button appears but cannot connect | Check channel activation, the exact allowed site address, the connected pool, and its members. |
| No response or an unavailable message | Check the pool Agents' running/responding state, concurrent sessions, and usage limits. |
| Moving the widget to another site | Register the new allowed site address and verify an actual response there. |
