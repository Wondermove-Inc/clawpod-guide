# Previous AI Chat guide

The customer menus checked for this guide do not expose a separate **OpenClaw AI / AI Chat** entry. This page does not promise that screen to every user.

To work with an Agent, select **Chat** at the top and follow the [Chat Room guide](./use-chat-room.mdx). For web tasks, verify the Agent's tools and permissions and follow [browser workflows](./use-browser-and-cli.mdx).

Do not guess internal addresses or broaden permissions to open an absent menu. This page preserves the previous documentation link.
