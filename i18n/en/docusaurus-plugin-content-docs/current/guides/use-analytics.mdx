# Review analytics and LLM costs

## Open analytics

Select **Admin** at the top, then open the following entries under **Analytics**. Visible menus and data depend on your role and permissions.

| Menu | What it shows |
| --- | --- |
| Overview | Active Agents, processed messages, total cost and tokens, LLM calls, conversations, and organization metrics |
| Costs | Total cost, model/organization/Agent costs, and daily spending |

Choose the period in each view. Compare the same period and organization scope. LLM usage costs are separate from subscription payments; use [plan management](./manage-billing.mdx) for the latter.

## Investigate changes

1. Review activity and error rates in Overview.
2. Compare cost changes with model, Agent, and usage changes in Costs.
3. If the cause remains unclear, review Agent details, logs, and related webhook Events.

Metrics alone do not establish a failure's cause or authorize configuration changes. Platform operations menus such as Monitoring and System are outside this customer workflow.
