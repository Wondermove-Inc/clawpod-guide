# Check usage and Agent status

## Check resource usage

1. Select **Admin** at the top and open **Dashboard**.
2. Find **Workspace Usage** and review the plan, member, organization, and Agent counts and limits.
3. If you manage subscriptions, open **Platform → Plans**. The billing screen also shows resource usage for organizations, users, and Agents.

These counts describe tenant resources, not an Agent's file workspace. You do not need a separate Workspace entry in Settings.

If a limit blocks creation, compare the required resources with the current limits and discuss cleanup or a [plan change](./manage-billing.mdx) with your tenant administrator.

## When an Agent does not respond

1. Open **Management → Agents** and check its status.
2. Open its details and review the available metrics and logs.
3. For webhook requests, check **Integrations → Webhooks → Events**.
4. If several Agents are affected, report the time and scope to the operations contact.

System and Monitoring are not required steps in this customer workflow. Do not guess addresses for menus that are not shown.

## If a menu is missing

Dashboard, Agents, and plan management depend on your role and allowed menus. Use the [Portal menu guide](../help/portal-feature-map.mdx) and ask your tenant administrator to check usage or status when you cannot access those views.
