# Review Dashboard and costs

Dashboard and cost entries depend on role and permissions. Start in **Admin** mode.

## Dashboard

1. Open **Dashboard** in the sidebar.
2. Choose the reporting period at the top.
3. Review quick insights, top Agents, recent activity, and workspace usage.
4. Open an Agent link or **Management → Agents** for more detail.

Workspace usage shows the tenant plan and member, organization, and Agent counts and limits. No separate Settings entry is required.

## LLM costs

Open **Analytics → Costs** to review total costs and model, organization, and Agent breakdowns for the selected period. See [analytics and costs](./use-analytics.mdx).

LLM usage analysis is separate from [subscription payment history](./manage-billing.mdx). Align the period and scope when comparing metrics.
