# Find Portal menus and guides

The **Chat / Admin** switch at the top changes the sidebar. Check the role shown in your account menu first. The management list below reflects a tenant administrator's view; ordinary members may see fewer entries according to their permissions and organization settings.

## Chat and personal settings

| Location | Purpose | Guide |
| --- | --- | --- |
| Chat → New chat / room search | Talk to Agents and find Rooms | [Chat Rooms](../guides/use-chat-room.mdx), [Previous conversations](../guides/use-chat-archive.mdx) |
| Room → Message search | Search loaded messages | [Message search](../guides/use-chat-room.mdx) |
| Room → Open workspace | Available PC/ClawPod controls, workboard, Artifacts, and meeting notes | [Desktop](../guides/use-agent-desktop.mdx), [Outputs](../guides/file-formats-and-artifacts.mdx), [Meeting notes](../guides/use-meeting-minutes.mdx) |
| Account at bottom left → Settings | Profile, password/MFA, appearance, and notifications | [Account settings](../guides/manage-account-and-organization.mdx), [Security](../guides/secure-your-account.mdx) |
| Account at bottom left → Language | Portal display language | [Language settings](../guides/manage-account-and-organization.mdx) |
| Top notification button → View all notifications | Notification history and delivery preferences | [Notifications](../guides/manage-notifications.mdx) |

The Chat workboard and the organization Tasks screen in Admin mode are different views. Available workspace tools and counts depend on the selected Room and Agent state.

## Missing menus

Check your role, current organization, selected mode, and allowed menus. Ask your tenant administrator if a needed entry is missing. **Documents, separate AI Chat/Chat Archive, Settings → Workspace/System, and Monitoring** are not baseline customer entry points in this guide. Do not guess URLs or broaden permissions just because an entry is absent.
