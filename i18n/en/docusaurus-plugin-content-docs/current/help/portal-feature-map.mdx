# Portal feature map

This map connects Portal menus to public guides. If a menu is missing, check role, Policy, tenant/organization scope, plan, and limits.

| Portal feature | Purpose | Guide |
| --- | --- | --- |
| Dashboard · Agents | Create and operate Agents | [Creation](../guides/create-agent.mdx), [management](../guides/manage-agent.mdx) |
| Chat · Chat Archive · AI Chat | Room conversations, attachments, mentions | [Chat Rooms](../guides/use-chat-room.mdx) |
| Documents · Tasks · Meeting minutes | Shared text documents, task boards, transcription and summaries | [Documents](../guides/manage-workspace-documents.mdx), [formats](../guides/file-formats-and-artifacts.mdx), [Tasks](../guides/use-tasks-and-milestones.mdx), [meetings](../guides/use-meeting-minutes.mdx) |
| Skills | Find, upload, download, install, and remove Skills | [Marketplace](../guides/manage-skills.mdx) |
| Credential · AI Key Management | Connect and rotate Agent credentials | [Credentials](../guides/manage-credentials.mdx) |
| Agent models | Main, sub, fallback, and heartbeat selection | [Providers and models](../guides/select-models.mdx) |
| Webhooks | Sources, Rules, Playbooks, and Events | [Webhooks](../guides/send-webhook-to-agent.mdx) |
| Organizations · Users · IAM | Organizations, members, direct Policies | [Organizations](../guides/manage-organization.mdx), [IAM](../guides/manage-iam.mdx) |
| Analytics · Costs | Agent activity, conversations, usage, and costs | [Analytics](../guides/use-analytics.mdx), [Dashboard/Costs](../guides/use-dashboard-and-costs.mdx) |
| AI Chat · Chat Archive | Personal AI sessions and accessible Room history | [AI Chat](../guides/use-ai-chat.mdx), [Archive](../guides/use-chat-archive.mdx) |
| Billing · Plans | Subscriptions, plans, and quota | [Billing](../guides/manage-billing.mdx), [Workspace/System](../guides/check-workspace-and-system.mdx) |
| Audit Log | Permission and administration records | [Audit Log](../guides/use-audit-log.mdx) |
| Notifications | Personal in-app/browser push preferences | [Notifications](../guides/manage-notifications.mdx) |
| Settings | Profile, appearance, usage, service health | [Sign-up/sign-in](../guides/start-account.mdx), [account settings](../guides/manage-account-and-organization.mdx), [security](../guides/secure-your-account.mdx) |

For missing menus or failed actions, check [availability](../capabilities/consumer-availability.mdx) and [help](./index.mdx). Agent browser and CLI tasks follow their [prerequisites](../guides/use-browser-and-cli.mdx). Platform operations menus are outside this map.
