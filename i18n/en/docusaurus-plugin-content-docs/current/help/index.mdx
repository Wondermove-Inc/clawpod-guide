# Help

If something goes wrong:

1. Verify the current organization and account.
2. Check roles and permissions if a menu or button is missing.
3. Confirm the required model and credential are connected for the organization.
4. If the problem continues, send the time, attempted action, error, and Agent name to your organization administrator or support.

Do not include secrets, access tokens, API keys, or full customer conversations.
